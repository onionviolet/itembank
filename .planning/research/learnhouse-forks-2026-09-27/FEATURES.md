# LearnHouse fork and independent variant review

Date: 2026-09-27. Status: source review for [the 114-row LearnHouse inventory](../LEARNHOUSE-GAP-INVENTORY-2026-09-27.md), not an adoption decision. No donor code was copied.

## Job and comparison rule

The useful jobs are: turn learner-owned sources into a reviewable course, help an author catch broken or incomplete activities, let a learner resume the right work, and handle feedback without creating a second scorer. I ranked evidence for those jobs over stars, ahead counts, feature volume, or resemblance to LearnHouse's hosted architecture. Itembank's accepted course files, source bindings, `runtime.py` score and disclosure, `journal.py` writes, and offline package recovery remain the comparison baseline.

**Source pins.** LearnHouse `dev` was [`5e28b072`](https://github.com/learnhouse/learnhouse/tree/5e28b0723176b34ba8777b9980db352268aa8234). The substantive fork heads were [SYSU-SAM `2c778307`](https://github.com/godarrenw/learnhouse/tree/2c778307db98827b030345e0a98943814b7c6a3a), [St. Joseph's `26682af5`](https://github.com/Shreesh-Sree/learnhouse-stjosephs/tree/26682af57106dabb7ebec77391aeed986d7c8cea), [Hybreed `75c1783d`](https://github.com/IAmHybreed237/learnhouse/tree/75c1783d7a0b51e4401da0edf477c159765fcb50), and [HeyVisions `e85316b9`](https://github.com/AidenNovak/heyvisions-lms/tree/e85316b92b53abd81737f1242187c625bcda01d8). Independent reference pins: [OpenTutor `db15d901`](https://github.com/zijinz456/OpenTutor/tree/db15d901a7c5c5f46941487ca4ebc2cfb20425c2) and [eXeLearning `f64d72fb`](https://github.com/exelearning/exelearning/tree/f64d72fb569b50fa22f89c1d861a2dfda44fb5d6). Checked each current default branch, a GitHub compare against LearnHouse `dev`, and the named paths below. All source observations are at those revisions.

## Search window, overlap, and confidence

GitHub listed 553 public forks at the check. I screened the first 100 forks sorted newest and the first 100 sorted by stargazers, then used compare results and changed-file paths to select the four lines above. This is a bounded sample, not a census of all forks, private forks, nondefault branches, or deleted repositories. `onionviolet/learnhouse`, `jmas3p/learnhouse`, and `LakChe-LTD/learnhouse` compared **identical** to upstream `dev`; `CallixteBailly/learnhouse` and `Wafercad/learnhouse` were **behind with zero ahead commits**. [Comparison query](https://github.com/learnhouse/learnhouse/compare/dev...godarrenw:sysu-sam) showed SYSU-SAM divergent, 112 ahead and 32 behind. [St. Joseph's](https://github.com/learnhouse/learnhouse/compare/dev...Shreesh-Sree:main) was 100 ahead and 32 behind. [HeyVisions](https://github.com/learnhouse/learnhouse/compare/dev...AidenNovak:dev) was 36 ahead and 19 behind. [Hybreed](https://github.com/learnhouse/learnhouse/compare/dev...IAmHybreed237:dev) was 8 ahead and 196 behind. Counts only guide where to inspect; they are not quality scores. The specific added paths discussed below are absent from the pinned upstream tree, so these variants were not merged into upstream at that pin. No branch was deployed or exercised by this review.

Evidence tiers: **route + call site + focused test** is stronger source evidence; **route + UI** shows reachability but not correctness; **documentation or screen captures** are author claims until reproduced. SYSU-SAM includes [focused backend tests](https://github.com/godarrenw/learnhouse/tree/2c778307db98827b030345e0a98943814b7c6a3a/apps/api/src/tests/ext), [Playwright specs](https://github.com/godarrenw/learnhouse/tree/2c778307db98827b030345e0a98943814b7c6a3a/apps/e2e/features/ext/tests), and [recorded QA](https://github.com/godarrenw/learnhouse/tree/2c778307db98827b030345e0a98943814b7c6a3a/docs/sysu-sam/QA). Those reports include local and deployment observations, but I did not reproduce them. St. Joseph's has selected service tests and UI files, while its [own status record](https://github.com/Shreesh-Sree/learnhouse-stjosephs/blob/26682af57106dabb7ebec77391aeed986d7c8cea/PENDING_FEATURES.md) repeatedly says new flows still need real-environment verification. The fork later added multi-hop cycle detection, so the older limitation paragraph in that record is stale relative to its pinned head; the actual [service test](https://github.com/Shreesh-Sree/learnhouse-stjosephs/blob/26682af57106dabb7ebec77391aeed986d7c8cea/apps/api/src/tests/services/test_prerequisite_cycle_detection.py) was also sampled and uses a simulated chain, not a database-backed end-to-end gate.

## Decision notes and limits

SYSU-SAM is the strongest source line for *author readiness* because it combines reachable routes, a tool UI, focused backend tests, browser tests, and QA notes. St. Joseph's has the widest set of institutional experiments, but its own caveats and mixed test depth keep most as prototypes or deferred references. Hybreed gives a visible learner return composition, while its progress percentage and schedule source are weaker fits than Itembank's objective evidence and Today owner. HeyVisions contributes small UI acceptance cases. Independent OpenTutor and eXeLearning reinforce the value of derived blocks and editable exports without requiring LearnHouse's database model.

This report did not install or run any fork, validate screenshots, test its deployed site, assess all transitive dependencies, or prove that a feature is human accessible. `PENDING_FEATURES.md`, QA tables, tests, and commit messages were treated as evidence leads, not release proof. Before any implementation, recheck the upstream and selected fork commit, license for the exact files, current Itembank packaged flow, an exact synthetic learner task, and the acceptance and recovery gate in the relevant inventory row. No shared inventory, vision, ledger, product source, learner data, or assessment format was edited by this fork review.
