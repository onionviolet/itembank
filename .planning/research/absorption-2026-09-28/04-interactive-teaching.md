## First slice and recovery

Choose one source-backed finite interaction in `surfaces/lesson_interaction.py`, ideally a linked quantity and line plot already supported by that renderer. Add one bounded authoring profile only if the present grammar cannot express the objective. The accepted Markdown and cited assets stay canonical; generated HTML and interaction state are derived. Compare plain and rich views, restart mid-task, and keep explanatory fallback visible when the renderer fails. No donor code or assets are copied by this report. Before a later import, pin the exact donor file and license, inspect transitive dependencies, preserve attribution, and validate the package and clean offline restore.

This report routes the large response-family backlog to its existing owner rather than claiming that each widget should ship now. Scientific correctness, accessible task equivalence and learning transfer remain human or domain review gates.
