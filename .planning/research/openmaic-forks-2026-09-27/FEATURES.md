## Exclusions and checks

- [Georgesuo Edge TTS adapter](https://github.com/Georgesuo/OpenMAIC/blob/d644fc4955ef42bbb76f145b24d52204eaa3cb3e/lib/audio/edge-tts-native.ts) is a fork delta, but itembank already has Edge TTS. The adapter also embeds a machine-specific Windows Python path, so it is not a portable integration reference.
- The standalone quiz fork's [`lib/quiz/scoring.ts`](https://github.com/Sid3548/OpenMAIC_sid/blob/d07726a33e7a252c2e1a185acf3fd2ade4b66d62/lib/quiz/scoring.ts) independently decides correctness and percentile. That cannot be imported into itembank's single-scorer runtime.
- [Automationnow offline HTML hook](https://github.com/Automationnow/OpenMAIC/blob/a9a8a041220b9b66235367c01ebc2d64acd0c950/lib/export/use-export-offline-html.ts) has a live source file but [its menu option was removed](https://github.com/Automationnow/OpenMAIC/commit/60d21d93004b). Do not label it a working one-click export without a UI trial.
- These findings are source-supported, not runtime-accepted. Compare links for each fork can be formed as `https://github.com/THU-MAIC/OpenMAIC/compare/f2875426ae5712d26f0a76e54e9de763e86027a6...OWNER:BRANCH`; commit links above identify the original change more precisely.
