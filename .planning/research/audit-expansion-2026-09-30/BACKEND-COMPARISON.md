## Selection and switching tests

Recommended now: PACKETS A1 and A2. Each begins with an actual native task
failure, preserves current owners and has a normal-route synthetic gate.
The extra backend mechanisms stay registered/prototype/backburner with their
named triggers. No architecture was dismissed simply because it has a backend,
and no whole platform was endorsed merely because one mechanism fits.

Independent adaptation carries local test and maintenance cost. Direct source
reuse carries notice/license, dependency updates, packaging, API compatibility
and upstream change review. Native reuse still carries integration and task
verification cost. None of those costs were benchmarked in this pass.

Every eventual adapter names exact source/model versions, rights basis, input
spans, egress, optional dependency availability, owner, accepted base and undo.
Queued work may propose; only native review/acceptance may publish. Indexes and
notebook outputs remain derived; source files, accepted revisions, learner
notes and runtime evidence retain their distinct truth owners.

## Evidence that would change these recommendations

A native task already completing A1 or A2 means document the existing proof
instead of implementing a duplicate. Measured query failure, blocked job
throughput, native extraction loss, real notebook/plugin use, history pressure
or a mismatch in a pinned scheduler comparator can promote the corresponding
retained mechanism. Good source structure and passing upstream tests cannot
establish local accessibility, scientific validity or learner benefit.
