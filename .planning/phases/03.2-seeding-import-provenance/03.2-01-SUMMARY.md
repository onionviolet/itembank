# Phase 03.2 Plan 01: Anki .apkg Import Summary

**The .apkg importer: a container reader (ZIP + conditional zstd + stdlib sqlite3), a documented note-type map with loud per-note refusals, a model.lint() gate every candidate passes, an exhaustive per-note report with zero silent drops, and an `itembank import anki` CLI that stages candidates for the accept loop without ever writing a bank.**

## Accomplishments
- `surfaces/import_anki.py`: `import_apkg(path, out, force)` reads the container (`collection.anki21b` decoded through the pinned `zstandard` binding, `collection.anki21`/`collection.anki2` through stdlib `sqlite3` with zero extra dependencies), maps note types through the documented `anki_note_type_map`, gates every candidate through `model.lint()`, and builds the exhaustive per-note report with the verbatim UI-SPEC 3 total line.
- Loud, named failures everywhere a silent drop could hide: `apkg.invalid_container`, `apkg.no_collection_member`, `apkg.zstd_missing`/`apkg.zstd_decode_failed`, `apkg.collection_unreadable`, `apkg.type_unsupported`, `apkg.media_path_traversal` -- every message names the file or note.
- `itembank import anki <file> --out <dir>` in `surfaces/cli.py`: writes `<deck>_import.md` and stages lint-clean candidates as deterministic `<deck>_candidates.json` for plan 03.2-03's accept loop; never writes a bank; works with no model backend; re-import is report-idempotent.
- `requirements.txt` pins `zstandard==0.25.0` with a recorded sdist sha256 (from PyPI, 2025-09-14) and the BSD-3-Clause license review -- the one non-stdlib dependency, conditional on the member type per 03.2-RESEARCH section 1 / Directive 4a.
- `tests/import_roundtrip.py`: 14 synthetic-fixture tests (never real data) covering both collection formats, named failures, the mapping/refusal/lint-gate, the exhaustive report, the CLI staging/no-bank-write/no-backend path, and re-import idempotency. The zstd half degrades gracefully when the binding is absent (asserts `apkg.zstd_missing`), so the suite passes with or without `zstandard` installed.
