key-decisions:
  - "Winnowing window default is 1 (every k-gram is its own min) so both metrics are deterministic and exactly testable; the algorithm is implemented generically and a larger window would trade run-exactness for a smaller fingerprint. Documented in model.py and the fixtures' expected Jaccard (0.33) is hand-derived, not calibrated."
  - "The copy check measures the longest run of consecutive candidate k-grams present in the source's k-gram hash set (run + k - 1 words) -- an 8+ word verbatim run is never missed, which a winnowed subset alone cannot guarantee. Both representations are hashes; the source text is never stored."
  - "The Jaccard overlap is the set Jaccard over the two texts' k-gram hash fingerprints; warn fires strictly above the threshold, error fires at or above the copy threshold."
  - "style.unsourced_specific lives inside the provenance pass: an item is 'sourced' exactly when it carries a [SRC:] that resolves in the bank's ## SOURCES registry. It fires only when provenance data is supplied (sources != sentinel), so the plain `itembank lint` path is unchanged."
  - "A [PREREQ:] target is resolvable when it is a case id, an item [ID:], or an objective any item teaches; when case data is present the legacy objective-only item.prereq_unknown warning is suppressed for case/item targets (a case prereq is valid, not a mystery objective). Truly unresolvable targets both keep the legacy warning and error prov.prereq_unknown."
  - "Cycle detection builds a graph over case ids and item [ID:]s (an item's node is its [CASE:] id when present, else its [ID:]); items with neither contribute no edges. Selection semantics over edges are explicitly NOT built -- Phase 7 owns them (D-16, deferred)."
