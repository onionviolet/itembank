# Phase 3.2 Style Warning Calibration

**Phase:** 03.2-seeding-import-provenance — plan 05 (verify)
**Status:** synthetic-corpus measurement recorded (D-18); real-corpus run is the human/private-bank action (D-17)

## What this table is

`itembank calibrate <corpus-dir> [--out 03.2-CALIBRATION.md]` runs every
Phase 3.1 style warning over a corpus directory and records, per warning:

- **fired** — how many corpus documents the warning fired on;
- **TP** — fired on a document that declared the warning expected
  (`<!-- CORPUS-EXPECT: <code> -->`);
- **FP** — fired on a document that did not declare it;
- **missed** — declared expected but never fired;
- **FP rate** = `FP / (TP + FP)` (0.00 when the warning never fires);
- **ship-state** — `enabled` below or at `style.warn_fp_threshold`
  (default **0.20**, `surfaces/settings.py`), `disabled by default` above it
  (`model.warning_ship_state`, plan 03.1-05's seam).

A warning therefore **ships enabled only with a recorded rate** (D-18). The
threshold is the `style.warn_fp_threshold` setting, default `0.20`.

The calibrated set is the closed content catalogue the style pass can emit
(`STYLE_CHECK_CATALOGUE`) plus `style.unsourced_specific` (plan 03.2-04), so
every Phase 3.1 content warning is measured, none assumed.

## Synthetic-corpus rates (measured by the plan-05 fixtures)

The rates below are what the plan-05 synthetic corpus is built to produce
(`tests/import_roundtrip.py` — three documents: a negative and a positive
`sentence_length` lesson, and a positive `unsourced_specific` dose item).
They are deterministic from the corpus construction. The corpus is entirely
synthetic (D-17); no real EMT / Math / CS content is in this repository.

**Parent verification (2026-08-11):** `python itembank.py calibrate
<synthetic-corpus> --out ...` was run and recorded exactly these rates —
`style.sentence_length` 0.50 → disabled by default, `style.require_marker`
1.00 → disabled by default, `style.unsourced_specific` 0.00 → enabled, all
other codes 0.00 → enabled. The table below is the executed measurement.

| code | fired | TP | FP | missed | FP rate | ship-state |
|---|---|---|---|---|---|---|
| style.order_before | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.heading_cadence | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.require_marker | 2 | 0 | 2 | 0 | 1.00 | disabled by default |
| style.forbidden_marker | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.open_with | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.section_density | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.sentence_length | 2 | 1 | 1 | 0 | 0.50 | disabled by default |
| style.filler_phrase | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.banned_hector | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.forbidden_phrase | 0 | 0 | 0 | 0 | 0.00 | enabled |
| style.unsourced_specific | 1 | 1 | 0 | 0 | 0.00 | enabled |

Reading: `style.sentence_length` fires once on a negative document (a false
positive) and once on a positive one (a true positive) — rate 0.50, so it is
**disabled by default** above the 0.20 threshold. `style.unsourced_specific`
fires once, on the document that declares it — rate 0.00, **enabled**.
`style.require_marker` fires on both lesson documents (the shipped house
rule requires a word-boundary `[SRC:]` token per section; the synthetic
lessons do not carry one), so its synthetic rate is dominated by that
artifact — the real-corpus run judges it.

## The real-corpus run — human action, never CI

The real EMT / Math 1400 / CSCI 1100 corpus lives **beside the private bank,
outside this repository** (D-17) and never enters this repo or CI. The
human/private-bank action to produce the true calibration is:

```text
python itembank.py calibrate <path-to-the-private-corpus-dir> \
    --out .planning/phases/03.2-seeding-import-provenance/03.2-CALIBRATION.md
```

That run overwrites this table with the real per-warning rates and ship-state
decisions. Until then, this table records the synthetic-corpus measurement
and the decision rule (D-18) — it is the deliverable, not a substitute for
the real run.
