# Phase 03.2 Plan 03: The Seeding Loop Summary

**The human-gated authoring loop: a six-stage pipeline in the locked D-08 order (deterministic source selection -> outline -> per-section drafting -> deterministic checks before any model critique -> independent verification -> human accept), one accept endpoint behind both the CLI and the daemon (D-07), a batch-framed browser surface that says so (D-09), and a refuse-by-name degrade when no backend is reachable (D-10).**

## Accomplishments
- `surfaces/seeding.py`:
  - `run_seeding_run(bank_path, adapter=None, objective=None, retry_cap=3, extra_checks=None)` -- the six-stage pipeline in the exact locked order. Stage 1 selects sources deterministically (sorted `## SOURCES` registry ids); stage 2 is the outline-only draft; stage 3 drafts each section of the outline and composes one parseable item block; stage 4 runs `model.lint()` with `parse_sources(bank_path)` passed plus the draft's own `[SRC:]`/`[OBJ:]` resolution against the registry and the plan 03.2-04 `extra_checks` seam, retrying within the cap; stage 5 is the independent CoVe-style second model pass over the deterministic-clean draft only; stage 6 is the human gate (`run.accept` / `run.skip` / `run.cancel`). A cancelled run writes nothing (D-09).
  - `accept_candidate(bank_path, candidate, ...)` -- the ONE accept endpoint: lint-gates the candidate (refusing on any error, reasons code-qualified), appends a clean item to the bank exactly once (content-fingerprint dedup), and returns a machine-readable result.
  - `render_candidate(q, number)` -- the deterministic render-then-write half: a `parse_question()`-shaped dict back into a bank `Qn.` block that re-parses and round-trips `content_fingerprint()`.
  - `render_accept_surface` / `render_cancelled_surface` / `render_degraded_surface` -- the batch-framed surface per UI-SPEC sections 2 and 4: the exact framing line, staged progress as a count, the candidate at text-body, the provenance line, the lint block, Accept/Skip/Cancel controls with Accept disabled WITH its reason on lint errors, no chat affordance, no fill bar, and the verbatim cancelled/degraded lines.
  - The Phase 8 adapter seam (`ModelAdapter`) documented in the module docstring -- hosted-first per Directive 1 -- with `NoBackendAdapter` (the D-10 default) and the deterministic `FakeModelAdapter` (headless tests). No real backend is built in this plan.
- `surfaces/cli.py`: `itembank seed <bank>` -- refuses by name with no backend (D-10), otherwise drives the accept loop reading `accept`/`skip`/`cancel` from stdin, calling the same `seeding.accept_candidate` the daemon route uses (D-07).
- `surfaces/daemon.py`: `POST /seed/accept` -- the daemon's half of the one accept endpoint: same-origin + loopback authority gate on the accept (mutating) action, bank stem resolved through the startup allowlist, `seeding.accept_candidate` called for accept, deferral/summary JSON for skip/cancel. Registered in ROUTES and ROUTE_CLI with the `seed` CLI twin.
- `tests/seeding_roundtrip.py`: 21 fixtures (stdlib, `fail()`/`main()` harness mirroring `tests/import_roundtrip.py`) covering all three tasks, all synthetic data.

## Decisions Made
- **Structural stage order**: `seeding.STAGES` is the locked tuple; the fixture asserts both the constant and `run.stages` -- a reorder fails the build.
- **Draft-level provenance check**: `_directive_errors` resolves the draft's own `[SRC:]`/`[OBJ:]` against the bank registry in stage 4 and at accept time, because `parse_sources` only reads the bank file.
- **Code-qualified reasons**: refusal/retry strings carry the dotted code (`item.missing_why_best (Q1: ...)`), matching how `import_anki` reports lint codes.
- **Exactly-once via fingerprint**: `content_fingerprint` dedup refuses a duplicate as `already_accepted`; a first accept appends once.
- **Fixed-literal route, not `/api/*`**: keeps `check_api_route_scope`'s exactly-five `API_ROUTES` assertion intact; ROUTE_CLI parity holds.
- **Loopback gate on accept only**: the mutating action requires a loopback client with a route-specific 403 message; skip/cancel do not write.
- **No chat, no fill bar**: verified structurally in the fixture (no input/textarea/progress/bar/% in the surface markup).
- **Adapter seam**: Phase 8 contract defined but not built; `FakeModelAdapter` makes the pipeline fully headless-testable; `NoBackendAdapter` is the D-10 default.
