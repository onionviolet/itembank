<objective>
**As the** runtime, **I want** every model interaction and every rubric suggestion to be a durable, append-only evidence fact, **so that** generated hints are recoverable by session, dropped output stays descriptor-only, and no model result can ever become accepted evidence without a human mark.

Purpose: TEACH-07 through TEACH-09 and MODEL-05 require useful audit/history without storing dangerous dropped bodies or granting the model scoring/writing authority (D-12..D-16, D-20..D-25).
Output: Versioned interaction/proposal event types, safe session retrieval, N-boolean read-time derivation, and the human-accept reference seam.
</objective>
