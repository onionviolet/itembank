<objective>
**As a** learner, **I want** optional generated guidance that can only ever use what the runtime already permits at my current hint tier, **so that** no model output — argued into it, prompted, malformed, or hallucinated — can reveal a key, the model answer, or a higher-tier fact before the runtime unlocks it.

Purpose: This is the phase's hardest constraint, scheduled first: the deterministic no-leak boundary must be proven before any provider is connected and before any learner-facing pixel ships (ROADMAP criterion 1, D-05..D-09).
Output: A production tier gate, a closed candidate contract, an authored-fallback seam, and a deterministic 30-plus-case adversarial corpus.

MVP note: the ROADMAP Phase 8 Goal line is not in user-story form; the story above is a derived framing recorded as an explicit planner assumption per `planner-mvp-mode.md`, consistent with the project's established plan set.
</objective>
