<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| private item/learner response -> candidate manifest | Key, rationale, reserved facts, and learner content enter the security policy boundary. |
| untrusted candidate -> runtime gate | Provider-controlled structured output must be rejected unless every reference is provably permitted. |
| gate result -> learner payload | Private classifications and dropped content must not cross into UI/API output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01-01 | Information Disclosure | `tier_gate.evaluate_candidate` | critical | mitigate | Closed schema, explicit permitted/reserved manifest, combination-aware checks, ambiguity-as-drop, and a checked-in adversarial corpus. |
| T-08-01-02 | Tampering | candidate fact/span references | high | mitigate | Resolve only stable manifest IDs and exact response spans; reject unknown, stale, higher-tier, and extra references. |
| T-08-01-03 | Elevation of Privilege | generated tier selection | high | mitigate | Consume Phase 6 entitlement as an immutable input; no model or gate field may select or advance tier. |
| T-08-01-04 | Information Disclosure | public pass/drop envelope | high | mitigate | Build learner payloads from an explicit allowlist and test private sentinel absence recursively. |
| T-08-01-05 | Denial of Service | malformed/oversized candidate | medium | mitigate | Enforce bounded candidate size/depth/counts before semantic checks and degrade to authored support. |
</threat_model>
