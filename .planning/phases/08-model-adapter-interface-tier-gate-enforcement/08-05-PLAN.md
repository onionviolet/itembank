<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser -> daemon | Untrusted identifiers, retries, and review decisions enter server authority. |
| daemon -> browser | Public results must exclude all private item/gate/provider state in JSON, markup, and accessibility text. |
| pending proposal -> trusted local reviewer CLI | Learner/agent/API surfaces remain proposal-only; local human authorization and actor identity are required for acceptance. |
| human checkpoint -> Phase 8 release | Responsive/accessibility/privacy/reviewer behavior requires recorded PASS evidence before Plan 08-06. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-05-01 | Information Disclosure | assist/review API and DOM | critical | mitigate | Identifier-only requests, runtime public envelope, recursive private-sentinel checks over JSON/HTML/DOM/ARIA/data attributes. |
| T-08-05-02 | Spoofing | session/interaction/proposal IDs | high | mitigate | Existing identifier allowlists plus server-side same-session/item/response relationship validation. |
| T-08-05-03 | Elevation of Privilege | proposal-linked accepted mark | critical | mitigate | No learner/browser/daemon/agent mark route; local attached-TTY reviewer command requires proposal link, designated actor ID, exact confirmation, and auditable authorization metadata beyond `marker=human`. |
| T-08-05-04 | Tampering | stale async response/retry | medium | mitigate | Match interaction IDs, abort/ignore stale responses, evidence-backed idempotency, explicit retry parent. |
| T-08-05-05 | Denial of Service | repeated browser generation | medium | mitigate | Opt-in only, one attempt per interaction, cancellation/stale containment, transport limits inherited from adapter. |
| T-08-05-06 | Repudiation | generated-vs-authored provenance | medium | mitigate | Persistent generated disclosure/source label and durable interaction/proposal links. |
</threat_model>
