<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| settings/environment -> transport profile | Local configuration selects executable/URL and optionally resolves a credential. |
| runtime request -> external process/server | Private item and learner content leave the process under explicit size/time bounds. |
| provider response -> normalized candidate | Untrusted stdout/HTTP content re-enters the runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-02-01 | Elevation of Privilege | hosted command execution | high | mitigate | Validated argument arrays, `shell=False`, no string shell composition, bounded subprocess timeout. |
| T-08-02-02 | Information Disclosure | secret resolution and diagnostics | critical | mitigate | Reference-only settings, late secret injection, redacted typed errors, sentinel tests over requests/results/diagnostics. |
| T-08-02-03 | Denial of Service | provider read/response parsing | high | mitigate | Request/output byte caps, bounded HTTP read, process/HTTP timeouts, closed JSON validation. |
| T-08-02-04 | Spoofing | local endpoint/profile selection | medium | mitigate | Exact named-profile resolution, supported URL schemes, explicit backend-class metadata, unknown-profile refusal. |
| T-08-02-05 | Tampering | provider candidate | high | mitigate | Normalize only schema-valid content and require the independent Plan 08-01 gate before rendering. |
</threat_model>
