<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| CLI/agent input -> session adapter | Untrusted identifiers and retry lineage select an existing session interaction. |
| session adapter -> runtime authority | Surface state must not override response, entitlement, score, or evidence policy. |
| usage contract -> agent behavior | The published contract limits what an automated consumer may infer or mutate. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-04-01 | Spoofing | session/interaction/retry identifiers | high | mitigate | Existing identifier allowlists plus same-session/item/operation evidence validation. |
| T-08-04-02 | Elevation of Privilege | CLI rubric workflow | critical | mitigate | Pending-only output and separate existing human mark path; run scorer/evidence authority tests. |
| T-08-04-03 | Information Disclosure | normalized CLI output | high | mitigate | Emit runtime public envelope only and scan private sentinels/provider metadata in source and `.pyz` runs. |
| T-08-04-04 | Repudiation | retry behavior | medium | mitigate | Required interaction IDs, evidence-backed idempotency, explicit parent-child lineage. |
| T-08-04-05 | Tampering | agent inference/permissions | medium | mitigate | Versioned schema-valid contract with explicit allowed/forbidden actions and no authority by implication. |
</threat_model>
