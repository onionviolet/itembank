# Phase 09.1 — Plan 09.1-02: The two real engines — edge-tts (network, MP3-native) and Piper (local, WAV + engine-scoped MP3), pinned and license-reviewed, with the D-16 disclosure in the command's own help

**edge-tts and Piper behind the plan 09.1-01 interface: both register by name, both refuse by name when missing or unreachable, the D-16 network disclosure is a tested string in the command's own help, and every third-party artifact ships pinned with a checksum and a license review read from the pinned version's actual license text.**

## Accomplishments
- `surfaces/audio_edge_tts.py`: `EdgeTTSEngine` (container "mp3") registered as `edge-tts`. Lazy `import edge_tts` inside `available()`/`speak()`; `available()` = import + endpoint probe; `speak()` streams MP3 chunks via `Communicate.stream()` and never transcribes. Missing library or unreachable endpoint -> `EngineError("edge-tts", ...)`.
- `surfaces/audio_piper.py`: `PiperEngine` (container "wav") registered as `piper`. Drives a bundled piper binary + model via subprocess (the recorded Phase 13 sidecar decision); WAV passes through untouched, MP3 converts through pinned lameenc only when the container setting says mp3.
- `surfaces/audio.py`: `configure(settings)` seam (engines read voice/model/container from settings; `--engine` overrides only the name), the roster comment documenting Kokoro as a registration target, and the two engine modules imported at the bottom so self-registration runs.
- `requirements.txt`: `edge-tts==7.2.8` (LGPL-3.0, sdist sha256) and `lameenc==1.8.4` (LGPL-3.0-or-later, cp311 win_amd64 sha256) pinned with named license reviews; the Piper bundled-artifact decision recorded explicitly.
- D-16 disclosure: "edge-tts sends item text to Microsoft's endpoint" sits in the `--engine` help and is asserted (whitespace-collapsed) by `test_edge_tts_disclosure_in_cli_help`.
- Roster contract: exactly {edge-tts, piper, transcript-only}; Kokoro documented, refusing by name if selected.
- No silent fallback at any level: unavailable configured engine -> transcript written, named refusal, non-zero exit.
