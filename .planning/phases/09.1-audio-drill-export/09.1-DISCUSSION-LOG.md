## Unreachable engine

| Option | Description | Selected |
|--------|-------------|----------|
| Emit transcript, name the engine and reason, exit non-zero | No silent substitution | ✓ |
| Silently fall back to the next engine | Always produces audio | |

**Choice:** named refusal. **Notes:** a silent fallback hands the learner a different voice and quality without saying so. Audio is written to a temp path and atomically renamed, so a failure never half-writes a file.

## Pack chunking

| Option | Description | Selected |
|--------|-------------|----------|
| `--split per-pack` (default) and `per-item`, both ship | One flag through one writer | ✓ |
| Per-pack only | Simpler | |

**Choice:** both (Directive §3). **Notes:** a pack is a commute, so per-pack is the default; per-item exists because skip-by-track beats skip-by-30s in some apps.

---

## Pause timing

| Option | Description | Selected |
|--------|-------------|----------|
| Setting with per-item-type defaults | A `build` ordering item needs longer than an `mc` recall item | ✓ |
| One constant | Simpler | |

**Choice:** per-type setting. **Notes:** the pause is the pedagogy; a single constant gets one of the item types wrong by construction. Defaults are recorded in the plan and tuned against use, not invented precisely.

## Evidence policy

| Option | Description | Selected |
|--------|-------------|----------|
| Listening records nothing | The log stays the record of what was answered | ✓ |
| A `listened` event | Feeds retention | |

**Choice:** record nothing. **Notes:** a "listened" event is an unfalsifiable claim about a file that left the machine. This was **rejected**, not deferred.
