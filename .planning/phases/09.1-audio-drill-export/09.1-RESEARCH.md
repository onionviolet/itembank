## Summary

Three findings:

1. **edge-tts licensing is a live review item, not a settled MIT.** PyPI and the project's setup metadata list **GPL-3.0** for recent versions, while several downstream packagers (FreshPorts, repology) show mixed MIT/LGPL records [WEB-VERIFIED: deps.dev PyPI record for edge-tts 5.0.3 shows GPL-3.0; repology shows GPL3/LGPL-3.0-or-later/MIT; freshports shows LGPL3 MIT; a 2023 setup.cfg states GPLv3]. The project is at ~v7.x and still reaches Microsoft Edge's online TTS service without an API key. The plan must treat the license as **unresolved until the pinned version's actual license text is read at vendoring time** (Directive 4a), and decide: pin a GPL-compatible posture (edge-tts as an optional engine, documented as GPL, never vendored into the product's own code), or select the MIT-licensed alternative. This is exactly the kind of thing D-15 exists for - and the research cannot close it from search snippets.
2. **Piper is MIT-licensed, local, and its models are ~30-114 MB, but its Python wheel story on Windows is the weak point.** Piper voices are MIT [WEB-VERIFIED: HuggingFace cstr/piper voice cards - "License: MIT"; medium models ~63 MB, high ~114 MB, small models smaller]. The `piper-tts` Python packages (piper-tts / piper-tts-plus) historically lacked Windows wheels for `piper-phonemize`, with community builds (piper-phonemize-bundled) fixing Python 3.12+ and recommending **Python 3.11 for wheel compatibility** [WEB-VERIFIED: piper-plus PR #189]. The plan must pin the exact wheel-bearing versions at implementation time; if no clean Windows wheel exists for the pinned Python, the fallback is to run Piper via its bundled binary/models (PyInstaller-shipped, per the Phase 13 sidecar pattern) - recorded as a plan decision, not a silent workaround.
3. **An MP3 encoder is needed for Piper (WAV-native) but NOT for edge-tts (streams MP3).** edge-tts saves audio directly as MP3 [WEB-VERIFIED: the library's save("...mp3") API - the endpoint streams MP3]. Piper emits WAV; converting to MP3 requires an encoder (lameenc is the small pure-wheel option; pydub+ffmpeg is heavier). The D-09 MP3 default is therefore engine-dependent: edge-tts writes MP3 natively; the Piper engine's MP3 path needs one pinned encoder (lameenc) or falls back to WAV when the container setting says WAV. transcript-only writes no audio.

## 2. The MP3-encoder question, resolved per engine

- edge-tts: **no encoder needed** - the endpoint streams MP3 and `save()` writes it.
- Piper: WAV-native; the MP3 default requires one pinned encoder (**lameenc**, the small wheel-based option; the heavier pydub+ffmpeg path is rejected on size/supply-chain grounds) or the WAV container when configured.
- transcript-only: no audio.

The plan should make the encoder engine-scoped: the Piper engine owns its MP3 conversion (lameenc pinned + license-reviewed), edge-tts writes MP3 natively, and the container setting (D-09) selects MP3/WAV.

## 3. The pack pipeline (composing with the locked decisions)

1. Resolve the objective's items (Phase 3.2 [OBJ:] registry; Phase 7 selection where available, else every item on the objective in bank order - CONTEXT integration points).
2. Build the sequence per D-06: stem - timed pause - key - why, with the pause duration from the per-item-type setting (D-07).
3. Call the configured engine through the `TTSEngine` interface (D-01); transcript-only always available (D-03).
4. Write audio temp-then-atomic-rename (D-05, the write_session() pattern); no silent fallback - on engine failure, emit the transcript, name the engine and reason, exit non-zero (D-04).
5. Emit the transcript always (D-11); name files from objective id + content digest (D-12); support --split per-item|per-pack (D-10); write no evidence (D-13).

## Validation Architecture

- The transcript-diff fixture: the audio pack's text equals the transcript's text in the same order (D-11 is diffable).
- The atomic-write fixture: a failing engine leaves no partial audio file.
- No evidence-write assertion: the fixture proves the evidence log is untouched (D-13).
