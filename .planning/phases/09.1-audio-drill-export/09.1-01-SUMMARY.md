# Phase 09.1 — Plan 09.1-01: Audio drill export tracer — TTSEngine interface, registry, transcript-only engine, CLI, and the audio settings block

**The whole audio-export spine with zero third-party dependencies: one TTSEngine interface with named registered implementations, a transcript-only null engine that makes 'refuse cleanly, still emit the transcript' fall out of the interface, the stem→pause→key→why sequence builder, the `itembank export audio` CLI, and the audio settings block — proven by fixtures before any real engine ships.**

## Performance

- **Duration:** ~50 min
- **Completed:** 2026-08-11
- **Tasks:** 3/3
- **Files modified:** 2 created (surfaces/audio.py, tests/audio_export_roundtrip.py), 4 modified (surfaces/cli.py, schemas/settings.schema.json, itembank.json, tests/config_roundtrip.py)

## Accomplishments
- `TTSEngine` interface (name/container/available/speak) + `TTSEngines` registry in `surfaces/audio.py`, copying the Phase 8 model-backend registry idiom — engines resolve by exact name, no dispatcher branch (D-01).
- `transcript-only` registered as a real engine: always available, `speak()` returns None (D-02/D-03).
- Unknown engine names raise `EngineError(name, reason)` — a named refusal, never a KeyError or silent default (D-04).
- `resolve_objective_items` reads the Phase 3.2 `[OBJ:]`/`## SOURCES` registry when present, else `[OBJECTIVE:]`/Educational Objective line; unknown objective ids refuse by name.
- `build_sequence` + `pack_transcript`: stem→timed pause→key→why per item with per-item-type pause durations; the transcript is the diffable contract (D-06/D-07/D-11).
- `export_audio(...)` is the one runtime call both surfaces reach (D-08); the CLI wraps it, and plan 03's daemon route will call the same function.
- The transcript is written **before** the engine attempt, so a missing/failing engine still leaves the transcript and a named, non-zero refusal (D-04/D-05); audio bytes are fully assembled before any write, so no partial file can exist.
- Digest-stable naming: `<objective-slug>-<sha256[:12]>` — unchanged re-exports are idempotent (D-12).
- `itembank export audio <bank> --objective <id> [--out DIR] [--engine NAME] [--split ...] [--container ...]` registered; the legacy flat `export <bank> <out> --format basic` is byte-identical to a pre-change golden (D-08).
- The `audio` settings block (engine/container/split enums + defaults, per-item-type pause map, edge_tts.voice, piper.voice/model) shipped in `schemas/settings.schema.json` and `itembank.json`, all marked `x-itembank-phase: 9.1`; `itembank config` prints the new keys.
- No evidence import or write anywhere in the audio module (D-13); the no-evidence fixture snapshots the log before/after and asserts byte-identity.
