## Trust Boundaries

| Boundary | Description |
|---|---|
| daemon HTTP body -> export | The route accepts bank/objective/out_dir from the network surface; the same runtime call validates it |
| engine bytes -> filesystem | Assembled bytes become files; temp-then-rename is the only writer |
| output names -> phone | Digest-stable names prevent silent overwrite of packs already copied to a device |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-091-SC | Tampering | writer duplication | medium | mitigate | One `assemble_pack` writer; the split flag is a mode, and the ROUTE_CLI inventory asserts route/CLI parity (D-08, D-10) |
