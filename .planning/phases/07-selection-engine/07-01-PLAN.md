> **Phase goal (quoted verbatim from `.planning/ROADMAP.md` § Phase 7 — this line is
> NOT in user-story form; run `/gsd mvp-phase 7` to convert it before the next replan):**
> A session is assembled by rule, not by hand — targeted at an objective, a difficulty,
> or a discrimination pair — and the tool can say why it picked each item.

<objective>
TRACER. Stand up `selection.py` as the one place an item is chosen, wire it end to end
through `do_start()` so both `itembank start` and `POST /api/start` reach it, and return
a trace that names a runner-up. One filter (objective), one ordering, one count policy —
the thinnest path that touches every layer this phase will later expand.

Purpose: prove the architecture (pure `select(questions, spec, history) -> (items, trace)`
per D-01/D-09, spec dict per D-02, trace per D-04/D-05) before five expansion plans build
on it. If the seam is wrong, it is wrong after one commit, not after six.

Output: `selection.py`, a selection fixture large enough to exercise this phase, a
synthetic evidence history, a running `tests/selection_roundtrip.py`, and a `do_start()`
whose inline `rng.shuffle` is gone.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv → `select()` | Learner-supplied flags become the selection spec |
| `/api/start` JSON body → `select()` | A loopback HTTP body becomes the selection spec |
| evidence log / sqlite3 index → `select()`'s caller | Recorded history is read and passed in |
| `select()` trace → learner | Trace text crosses the same public/private boundary `runtime.public_item()` enforces |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Denial of Service | `selection.select()` count handling | medium | mitigate | `do_start()`'s positive-integer guard moves into `select()` verbatim (Task 2) and the count is clamped to the candidate pool; `handle_api_start` keeps coercing a non-int `count` to 10 |

| T-07-05 | Tampering | `exclude_item_ids` handling | medium | mitigate | `select()` opens no file (D-09); `exclude_item_ids` values are only compared against in-memory `evidence.evidence_key(q)` strings, never joined to a path |
