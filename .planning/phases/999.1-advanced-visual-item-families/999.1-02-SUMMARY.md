## What this plan set out to do

Add the `timeline` family to protocol 1 (D-999.1-01): the learner places one
authored event label at a canonical SCALAR time value on an axis. This is the
first *continuous-valued* family in the phase, proving the extension pattern
for value + per-coordinate tolerance — the pattern plan 03's trace family
(vector-valued) builds on.
