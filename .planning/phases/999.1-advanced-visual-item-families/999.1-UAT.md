# Phase 999.1 — UAT

**Phase:** 999.1-advanced-visual-item-families
**Date:** 2026-08-11

Each scenario is executable from the repository using the synthetic fixture
`fixtures/advanced_visual_bank.md`. Every claim below was exercised by the
roundtrip tests listed in the scenario.

## Scenario 1 — Author: the four families lint clean and the spec is enough

**Visible state:** a bank author writes hotspot, timeline, diagram, and trace
items from `python itembank.py spec` alone.

- `python itembank.py spec` documents `[INTERACTION: hotspot | timeline |
  diagram | trace]`, each scene member set, each wire response, each action,
  and the tolerance rules.
- `python itembank.py lint fixtures/advanced_visual_bank.md` → 12 items,
  0 errors.
- An author who gets the grammar wrong receives a named, field-addressed
  code: `item.visual_invalid_geometry` (malformed plane/regions/events/nodes/
  point_count), `item.visual_duplicate_id` (duplicate ids), 
  `item.visual_unknown_member` (scene member outside the per-interaction
  allowlist), `item.visual_invalid_axis`, `item.visual_unknown_scoring_kind`
  (kind/`INTERACTION` mismatch), and the exact-id tolerance error.
  **Proof:** `check_lint` sections of all four roundtrip tests.

## Scenario 2 — Learner: answer each family through the served surface

**Visible state:** a served sitting presents each family as an inline SVG
scene with adjacent semantic controls, a Commit move control, and Check
response.

| Family | Interaction (served) | Correct response submitted | Score |
|---|---|---|---|
| hotspot | click region or radio | `{"kind":"hotspot","region":"heart"}` | True |
| timeline | event + value selects or click | `{"kind":"timeline_event","event":"fall","value":"5"}` | True |
| diagram | click source then target, or from/to selects | `{"kind":"diagram_connection","from":"a","to":"c"}` | True |
| trace | click places points in order, per-point selects | `{"kind":"trace_path","points":[...3 points...]}` | True |

**Proof:** the served sections of `hotspot_roundtrip.py`,
`timeline_roundtrip.py`, `diagram_roundtrip.py`, `trace_roundtrip.py` each run
a full 12-item served sitting and assert every submit scores True; the wrong
answers (wrong region, wrong event/year, reversed pair, shifted/misordered/
short path) score False.

## Scenario 3 — Learner: wrong answers give bounded, leak-free observations

**Visible state:** after a committed move, the polite status region shows the
runtime's bounded observation; no accepted state, tolerance, or reveal
material appears.

- hotspot unknown region → `error_category: unknown_region`
- timeline unknown event → `unknown_event`; out-of-axis value → `out_of_domain`
- diagram self-loop/unknown node → refused; `unknown_node` when a node is
  unknown
- trace short path → refused (`wrong_point_count`); out-of-domain point →
  `out_of_domain`
- The public item and every observation/evidence payload scan clean of
  `accepted`/`tolerance`/`partial_credit`/`scoring`/`reveal` sentinels.

**Proof:** observation + sentinel sections of all four roundtrip tests and
`visual_evidence_roundtrip.py`.

## Scenario 4 — Agent: the committed-action trail is queryable

**Visible state:** a teaching agent reads the append-only `visual_action`
trail and sees exactly one event per changed commit, in order, with canonical
before/after states and no pointer noise.

- `select_hotspot`, `place_timeline_event` → `move_timeline_event`,
  `connect_diagram`, `place_trace_point` → `move_trace_point` each append one
  event; identical retries replay as `already_recorded`; id reuse with
  different state is a `conflict`.
- Every event validates against `schemas/visual_interaction.schema.json`
  with the locked field set.

**Proof:** interact/evidence + schema sections of all four roundtrip tests.

## Scenario 5 — Exporter: GIFT refuses every visual family loudly

**Visible state:** a mixed bank exports its expressible items and refuses each
of the six visual items (plot, numberline, hotspot, timeline, diagram, trace)
by original item number with `gift.type_unsupported` in default and strict
modes; no lossy approximation, no private/scene leakage.

**Proof:** `tests/gift_export_roundtrip.py` PASS (refusal count 6).

## Scenario 6 — Offline: static build refuses honestly

**Visible state:** `python itembank.py build fixtures/advanced_visual_bank.md
out.html` produces a page that says every visual item needs a served itembank
session; no key or scoring material appears.

**Proof:** offline sections of all four roundtrip tests.
