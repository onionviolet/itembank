|----------|-------------|
| Bank markdown -> model/runtime | Declarative diagram/trace scenes and private accepted material enter validation; ids/labels/coords must never become executable code. |
| Runtime -> public browser/agent contract | Nodes and the trace reference polyline cross to an untrusted consumer; accepted connections/paths and tolerance stay server-side. |
| Browser/agent -> runtime scorer | Untrusted diagram/trace responses and forged fields cross into validation and scoring. |

|-----------|----------|-----------|----------|-------------|-----------------|

| T-999.1-10 | Information Disclosure | diagram/trace public projection | high | mitigate | Public contract carries scene/initial/actions/accessibility only; extend the sentinel scan; accepted path never projected. |
| T-999.1-11 | Tampering | diagram submit | high | mitigate | Exact wire-shape grammar; unknown nodes and self-loops fail closed. |
