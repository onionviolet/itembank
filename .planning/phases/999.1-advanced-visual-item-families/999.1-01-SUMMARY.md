## What this plan set out to do

Add the `hotspot` family to the Phase 06.1 visual protocol as the first
additive protocol-1 extension (D-999.1-01): same envelope, same
interact/evidence machinery, closed per-interaction scene allowlists — and
prove it end to end from parser through key-free contract, exact-id scoring,
runtime-bounded observation, committed `select_hotspot` evidence, the served
renderer, and GIFT refusal.

  byte-identically.
- Hotspot scoring is exact region-id equality; a non-zero tolerance is an
  authoring error; forged fields are rejected by the exact wire shape.
- Public payloads carry no `accepted`/`tolerance`/`partial_credit`/`scoring`
  sentinels; observations carry `known_region`/`unknown_region` only.
- Renderer is SVG + radio-list semantic control, no canvas; the offline
  static page refuses hotspot items with the served-runtime copy.
