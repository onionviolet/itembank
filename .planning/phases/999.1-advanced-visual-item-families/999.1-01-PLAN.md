<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bank markdown -> model/runtime | Declarative hotspot scene and private accepted region enter validation; ids/labels/coords must never become executable code or unvalidated markup. |
| Runtime -> public browser/agent contract | Scene/region geometry and actions cross to an untrusted consumer; the accepted region and feedback anchors stay server-side. |
| Browser/agent -> runtime scorer | Untrusted hotspot responses and forged authority fields cross into validation, canonicalization, and scoring. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-999.1-01 | Elevation of Privilege | bank hotspot configuration | high | mitigate | Closed per-interaction scene allowlist plus the existing `_reject_visual_exec` scan on ids/labels/coords before render. |
| T-999.1-02 | Information Disclosure | hotspot public projection | high | mitigate | Public contract carries plane/regions/initial/actions/accessibility only; assert accepted/tolerance/feedback sentinels never appear (extend the 06.1 sentinel set). |
| T-999.1-03 | Tampering | hotspot submit | high | mitigate | Exact wire-shape grammar rejects extra keys (forged verdict/tier); unknown region ids fail closed as invalid. |
| T-999.1-04 | Denial of Service | scene geometry | medium | mitigate | Bound region count (<= 200), id length (<= 64), coordinate SCALAR bounds via the existing grammar. |
| T-999.1-SC | Tampering | package supply chain | low | accept | No package-manager install; stdlib + browser-native SVG/HTML/JS. |
</threat_model>
