- The lesson page keeps its own `LESSON_TEMPLATE` document instead of
  `surface_shell` because the locked order is theme + shared + lesson and
  `surface_shell` appends SHARED_CSS last; the composition is imported, not
  duplicated, so `surfaces/study.py` needed no change.
- `LESSON_CSS` uses only the locked project scale sizes and the 400/600
  weight pair; fonts resolve exclusively through `var(--font-paper)` /
  `var(--font-ledger)`.
- `--r-2`/`--r-3` landed in `SHARED_CSS` (UI-SPEC §2 ownership): Task 1's
  plan text enumerated voice/measure/leading only, but the callout contract
  requires `--r-3`.
- `[!CHECK: <id>]` renders the inert slot and drops the id entirely so no
  key-shaped material enters the DOM (D-18).
