# Source: model.py:145-164 — call this verbatim for every term key and anchor id
def lesson_slug(text):

def _split_cells(row):
    row = row.strip()
    if row.startswith("|"):
        row = row[1:]
    if row.endswith("|"):
        row = row[:-1]
    return [c.strip() for c in row.split("|")]

    return all(re.match(r"^:?-+:?$", c) for c in _split_cells(row))

### `surfaces/anki.py` — `[!KEY]` export path (`#guid` round-trip)

**Analog:** `surfaces/anki.py:17-46 cmd_export()` — quoted in full (file is 47 lines).

```python
# Source: surfaces/anki.py:1-46 — the complete current exporter
"""Anki TSV export: Basic and Cloze, generic to any bank.
...
"""
import os, re, sys

from model import lint, load
from runtime import answer_text
from surfaces import gift


def tsv_cell(value):
    return re.sub(r"\s+", " ", str(value or "")).replace("\t", " ").strip()


def cmd_export(a):
    if a.format == "gift":
        return gift.export_gift(a)
    qs = load(a.bank)
    errors, _ = lint(qs)
    if errors and not a.force:
        sys.exit("refusing to export a bank with errors; fix them or pass --force")
    rows = []
    for q in qs:
        front = q["stem"]
        answer = answer_text(q)
        if a.format == "cloze":
            text = "%s {{c1::%s}}" % (front, answer)
            rows.append("%s\t%s" % (tsv_cell(text), tsv_cell(q.get("why") or q.get("disc"))))
        else:
            options = ""
            if q["type"] in ("mc", "multi"):
                options = " Options: " + " | ".join("%s) %s" % (k, q["opts"][k]) for k in sorted(q["opts"]))
            rows.append("%s\t%s%s" % (tsv_cell(front + options), tsv_cell(answer),
                                       ("<br><br>" + tsv_cell(q.get("why"))) if q.get("why") else ""))
    header = ["#separator:tab", "#html:true"]
    if a.format == "cloze":
        header += ["#notetype:Cloze", "Text\tExtra"]
    else:
        header += ["#notetype:Basic", "#tags column:3", "Front\tBack\tTags"]
        rows = [row + "\titembank" for row in rows]
    os.makedirs(os.path.dirname(a.out) or ".", exist_ok=True)
    open(a.out, "w", encoding="utf-8").write("\n".join(header + rows) + "\n")
    print("%d items -> %s" % (len(qs), a.out))
    return 0
```

**Exact gap confirmed:** no `#guid` column anywhere; `header` is a flat list of two fixed strings (`"#separator:tab"`, `"#html:true"`) plus one notetype-specific pair; `rows` iterates `qs` (items), never lesson/`[!KEY]` blocks. Anki's own `#guid` column convention (a `#guid:1` header directive naming which TSV column holds the stable note guid, per Anki's documented text-import format) does not exist in this code at all.

**What the new `[!KEY]`-export function must add, following this file's exact idioms (`tsv_cell()` for every field, `header + rows` list-join, `os.makedirs(...)` + single `open(...).write(...)`, final `print("%d items -> %s" % ...)` status line):**
- A new function (e.g. `cmd_export_keys(a)` or a branch inside `cmd_export` keyed on a new `a.format == "keys"`), iterating `[!KEY]` blocks (from `parse_lesson()`/the new callout parse, not `load()`'s item list).
- `header` gains `"#guid:1"` (or wherever the guid column lands) alongside the existing `"#separator:tab"`/`"#html:true"`/`"#notetype:..."` lines.
- Each row's first cell is the `[!KEY]` block's `[ID:]` value (already minted via `new_item_id()`/the shared `taken` set — see the `model.py` id-minting pattern above), passed through `tsv_cell()` exactly like every other field here.
- `{{cloze}}` markers pass through unescaped into the TSV cell (Anki's own cloze syntax), following the existing `"%s {{c1::%s}}" % (front, answer)` cloze-row-construction idiom already present for the `a.format == "cloze"` branch.
- Round-trip (re-export reusing the same guid for an unchanged `[ID:]`) is proven by test, not asserted — follow `tests/lesson_roundtrip.py`'s `fail()`-based harness style (no test framework), per D-22.
