## Trust Boundaries

| Boundary | Description |
|---|---|
| bank/objective -> profile selector | Author-controlled objective namespaces influence the persisted runtime profile |
| stored session -> resumed runtime | On-disk JSON may be stale, legacy, or edited before resume |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-09-02 | Tampering | session resume | high | mitigate | Version the session addition, persist the full resolved snapshot, and consume that snapshot after start rather than current registry data. |

| T-09-04 | Elevation of Privilege | presentation capability flags | medium | mitigate | Keep capability data out of `teaching_transition`, `score_response`, and `append_event`; tests assert those owners remain unchanged. |
