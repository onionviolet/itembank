## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| documentation → reader | this is the boundary CODE-05 governs: what the reader is told the runtime guarantees |
| daemon/CLI → spawned interpreter | attacker-influenced code is executed here, by design |
| spawned interpreter → host OS | **no boundary is enforced here.** Filesystem and network reach are unrestricted |
| evidence log → later reader | a `check` submission's source must be readable by a marker or a later model |
