<objective>
Publish the visual authoring contract and make semantic learner actions/observations durable and agent-queryable through one CLI/API/runtime path.

Purpose: A visual renderer is useful to the agentic teaching loop only when authors can reliably generate its declarative contract and teaching agents can inspect meaningful committed moves without receiving raw telemetry, private scoring state, or authority over feedback tiers.
Output: Stable visual lint codes and schemas, a golden authoring fixture, a versioned append-only visual-action event, session/item queries, and CLI/API twins for committing an action and receiving its runtime observation.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Author/model -> bank grammar | Untrusted declarative JSON must remain bounded data and satisfy accessibility/scoring invariants. |
| Browser/agent -> `/api/interact` | Untrusted semantic action documents cross into session state, runtime policy, and append-only evidence. |
| Evidence -> teaching agent | Local durable history is projected into a bounded observation trail without private answer material. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.1-05 | Elevation of Privilege | visual authoring grammar | high | mitigate | Closed schema/lint allowlists reject executable/script-bearing and unknown members before a renderer sees them. |
| T-06.1-06 | Tampering | `/api/interact` | high | mitigate | Resolve session/current item server-side, reject authority fields, validate version/action/state, and obtain observation/tier from runtime policy only. |
| T-06.1-07 | Information Disclosure | visual action evidence query | high | mitigate | Project a positive allowlist of semantic state/opaque anchors; exclude scoring envelopes, accepted state, tolerance, reveal content, and paths. |
| T-06.1-08 | Denial of Service | interaction event stream | medium | mitigate | Accept commit operations only, cap document/state sizes, dedupe action IDs, and provide no raw movement-stream route. |
| T-06.1-SC | Tampering | package supply chain | low | accept | No package-manager install occurs; all validation, API, and evidence work uses repository/stdlib primitives. |
</threat_model>
