# Phase 06.1: Interactive Visual Assessment Protocol - Context

**Gathered:** 2026-08-08
**Status:** Ready for execution planning
**Mode:** autonomous reconciliation of prior authority

<domain>
## Phase Boundary

This phase proves one vertical visual-assessment tracer: declarative plot and number-line items become key-free semantic public payloads, accept modality-independent semantic actions, are scored only by the runtime, and append meaningful committed-action evidence. It does not add arbitrary simulations, canvas-only interactions, QTI/LTI, hosted identity, grade passback, or a second scorer/parser.
</domain>

<decisions>
## Implementation Decisions

### Protocol and scoring
- **D-01 (LOCKED):** Protocol integer `1` covers plot points, number-line points, and intervals. Coordinates use the exact `SCALAR` grammar and `fractions.Fraction` canonicalization already resolved in `06.1-RESEARCH.md`; browser floats and pixels are never evidence or scoring inputs.
- **D-02 (LOCKED):** `runtime.score_response()` remains the sole scorer. Accepted states, tolerance, misconception mapping, reveal content, and solution paths remain private.
- **D-03 (LOCKED):** The public contract contains only scene, initial state, allowed semantic actions, response grammar, and accessibility text. Static output refuses honestly when the served runtime is required.

### Interaction and evidence
- **D-04 (LOCKED):** Only successful state-changing commits append `visual_action`: native commit/Enter/Space, tap, or pointer-up after a changed drag. Movement, focus, hover, zoom/pan, cancellation, tentative state, and unchanged commits append nothing.
- **D-05 (LOCKED):** The only action types are `place_point`, `move_point`, `select_numberline_point`, and `set_interval`; final submit remains the ordinary response event. The five-field request, UUID-v4 action identity, dedupe behavior, observation fields, and exact stored event shape are those resolved in `06.1-RESEARCH.md` item 2.
- **D-06 (LOCKED):** Phase 6 owns hint entitlement. Visual feedback exposes only an opaque anchor and bounded observation; Phase 8 may later phrase a typed runtime-gated payload but cannot score, infer the answer, or advance a tier.

### Renderer and accessibility
- **D-07 (LOCKED):** The initial renderer is SVG enhanced by an adjacent, fully operable semantic HTML control/state path. Mouse, touch, keyboard, and native controls reduce through one state reducer and serializer and must produce byte-identical semantic actions for equivalent states.
- **D-08 (LOCKED):** The 320 CSS px, 200% zoom, visible-focus, status-announcement, reduced-motion, pointer-cancellation, and non-drag alternative gates in `06.1-UI-SPEC.md` are completion requirements, not preferences.
- **D-09 (LOCKED):** GIFT refuses visual items by original item number and `gift.type_unsupported`; no lossy approximation is allowed.

### Codex's Discretion
Implementation may choose internal names and module factoring consistent with the plans. It may not widen the visual taxonomy or weaken exact-scalar, public/private, evidence, accessibility, or sole-scorer boundaries.
</decisions>
