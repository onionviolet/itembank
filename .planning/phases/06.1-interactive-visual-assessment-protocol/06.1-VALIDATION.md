## Locked Protocol Fixtures

### Coordinate grammar

The tests must include and preserve these canonical response shapes from `06.1-RESEARCH.md`:

- Plot: `{"kind":"point","x":"2","y":"3"}`
- Number-line point: `{"kind":"numberline_point","value":"1/2"}`
- Interval: `{"kind":"interval","start":"-1","end":"3/2","start_closed":true,"end_closed":false}`

They must also prove rational reduction, decimal trailing-zero removal, negative-zero normalization, reversed-interval closure swapping, exact step alignment, the 201-tick cap, bounded numerator/denominator, and refusal of exponents/non-finite/symbolic values.

### Committed-action contract

The evidence/API tests must pin:

- Request keys exactly: `session_id`, `interaction_version`, `action_id`, `action_type`, `state`; `action_id` matches the locked lowercase UUID-v4 regex.
- Action enum exactly: `place_point`, `move_point`, `select_numberline_point`, `set_interval`.
- Evidence keys: the common audit fields plus `interaction_version`, `action_id`, `action_type`, `before_state`, `after_state`, `error_category`, `invariants`, `feedback_anchor`, `hint_tier`, and `dedupe_key`.
- Append boundary: explicit successful state-changing commits only; final submit is an ordinary response event.
- Retry behavior: identical action ID/action/state returns `already_recorded`; the same ID with changed action/state is a conflict.
