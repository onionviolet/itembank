## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Input device/browser DOM -> semantic action API | Pointer/touch/key events are untrusted UI signals and must reduce to the same validated domain action. |
| Visual public contract -> accessibility tree | SVG enhancement and semantic fallback must expose equivalent operable state without revealing scoring secrets. |
| Visual item -> GIFT exporter | An unsupported assessment crosses an interchange boundary that cannot preserve its semantics. |
