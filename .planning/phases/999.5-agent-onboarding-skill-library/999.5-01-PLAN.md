### Task 2: Sync `guiding-questions` to the shipped tutoring surface

Add to the skill, before "Close with evidence", a short section on the
tier-gated hint ladder and rubric review, documenting only shipped flags:

- `python itembank.py hint --session s.json` — one error-specific hint; the
  runtime owns the tier ladder (`tier.index`), falls back to the authored
  tier offline, never accepts a caller-supplied tier (D-09); `--retry`
  regenerates as a parent-linked retry (at most one generation per
  interaction id otherwise, D-12).
- `python itembank.py rubric-review --session s.json` — pending per-point
  rubric suggestions for the current `short` response; a model suggestion can
  never settle a mark (D-25); the only surfaced form is a single `pending`
  token.
- `python itembank.py select bank.md [--objective ... --type ... --seed N
  --count N --explain]` — preview a selection without starting a session;
  `--explain` prints the "why this item" trace (Phase 7).
- Keep the boundary lines intact: the tutor never decides a tier, never
  reveals higher-tier content the runtime has not granted.

### Task 3: Sync `curriculum-design` to the coverage command

  distinct from `stats` (item mix/position) — coverage is objective-level and
  citation-backed.
- Tie the existing "cannot cite the item, do not claim coverage" boundary to
  the `## SOURCES` registry.
