## What shipped

1. **README rewritten from the frozen shipped surface.** The front door now
   opens with a 10-second summary and a five-line sample bank before any
   architecture; "Why this exists" is kept nearly verbatim; the four-layer
   model/runtime/server/surfaces paragraph moved to the Design section. The
   flat 13-command block is replaced by grouped, aligned command index
   covering **all 44 registered subcommands** (frozen at execution time from
   `python itembank.py --help`, cross-checked against `add_parser(` in
   `surfaces/cli.py`): core loop, JSON sessions for agents, evidence and
   marking, learning surfaces, data and tools. Every documented command,
   flag, and positional was verified against `--help` at write time (e.g.
   `hint --session`, `rubric-review --session`, `override <bank>`,
   `interact --action <json> <session>`, `export <bank> <out> --format
   {basic,cloze,gift,keys}`, audio drill pack via `--objective`).
2. **Spec contract heading corrected — the plan's carve-out.** `model.py`'s
   spec text now prints `THE SEVEN ITEM TYPES` (was FIVE; `visual` shipped
   via 06.1-01/02), and the two assertions in `tests/lesson_roundtrip.py`
   that pin the heading were updated to match. No other behavior in
   `model.py` or the tests changed.
3. **Item-type documentation agrees with the spec.** README lists all seven
   shipped types (`mc`, `multi`, `table`, `build`, `dnd`, `short`,
   `visual`), with `visual`'s declarative-JSON-never-executed one-liner. The
   NREMT framing was **removed**: `itembank spec` contains no NREMT mention
   (grep count 0), so the plan's "keep only if still the design note" test
   failed and the dichotomous rule is stated directly ("Two of three correct
   scores zero"). `check` (Phase 5) is not documented.
4. **Design boundaries reconciled with what ships.** The "does not do spaced
   repetition" bullet is rewritten: `retention.py` derives due state and
   daily caps by replaying captured evidence through one scheduler strategy
   (FSRS is the registered default), surfaced as `itembank trends`, the
   `day` recommendations, and the retention report variant — while stating
   it is **not** a per-card recall scheduler and `study`'s Learn loop stays
   session-only. No invented tok/s/latency/capacity figures (D-19). A new
   bullet covers the Phase 8 model adapter: optional hosted/local backend
   may generate hints and marking suggestions, the runtime gates tiers
   (`tier_gate.py`), and a suggestion is a `pending` token until a human
   marks it — nothing a model produces is accepted as evidence or a score.
5. **Layout tree is real.** Rebuilt from `ls` at execution time: root
   modules (including `evidence.py`, `retention.py`, `selection.py`,
   `model_adapter.py`, `tier_gate.py`, `build.py`, `schema_validate.py`),
   `surfaces/` (26 client modules), `schemas/` (12), `styles/` (6),
   `launchers/` (3), `installers/`, `scripts/`, `src-tauri/`, fixtures,
   tests, GRADING/AGENTS/skills/ROADMAP lines. No invented paths; the
   "session files are private output" note is kept.
6. **Bounded drift pass.** `AGENTS.md` item-type list gains `visual`; every
   command AGENTS.md names exists in `--help`. ROADMAP's phase-status table
   corrected to the execution-time STATE.md truth (see below). GRADING.md's
   stale "a model's verdict is not accepted evidence in this milestone"
   section replaced with the shipped proposal flow (mark_proposal events,
   `itembank mark --proposal`, marker always `human`, D-14/D-24). CLAUDE.md
   "six item types" → "seven". `.agents/skills/` and `.claude/skills/`
   content untouched (byte-identical mirrors verified).
7. **Two CI gates.** (a) Claim-word gate: new
   `scripts/check_readme_commands.py` runs `itembank.py --help`, extracts
   bare command tokens from README fenced code blocks, fails on any token
   not a registered subcommand (flags not checked); wired into CI. (b) Full
   schema coverage: `schema_validate.py` gains an `--all` mode that
   structurally self-checks every `schemas/*.json` (parse + whole
   `check_schema` walk); CI runs `python schema_validate.py --all schemas`,
   and the workflow comment maps each of the seven formerly-uncovered
   schemas to its real-payload roundtrip test — no schema is silently
   absent.
8. **Broken-windows ledger audited to truth.** Window 1 (daemon
   reserved-port/EACCES branch) is **closed** by a portable repro added to
   `tests/daemon_roundtrip.py` (`check_startup_reserved_port_falls_back` —
   the plan's second carve-out): the Daemon constructor is patched to raise
   exactly the OSError the branch keys on, `probe` is patched to fail the
   test if the EACCES path touches it, and the fallback must serve. Windows
   2 (LAN phone reachability) and 3 (GIFT sandbox manual import) are
   assessed as genuinely manual, left open with what-closes-each and who
   must do it; frontmatter `open_count`/`fixed_count` updated to match
   (2/1).
