<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser edit JSON -> plan adapter | Untrusted revision/cell/token fields request mutation of a local human-authored file. |
| Plan stem -> filesystem path | The daemon resolves an identifier to one startup-allowlisted plan; the client never supplies a path. |
| Conflict UI -> forced replacement | A destructive exception becomes available only after a verified stale-write conflict. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-21 | Tampering | `/day/<stem>/edit` | high | mitigate | Resolve allowlisted stem, reject path/full-document/authority fields, validate cells, and delegate exact-byte comparison/atomic patch to day_document. |
| T-04-22 | Tampering | concurrent plan edit | high | mitigate | SHA-256 compare fresh bytes immediately before every normal/force replace; conflict writes nothing and preserves both sides. |
| T-04-23 | Elevation of Privilege | force overwrite | high | mitigate | Issue cryptographically random one-use token after conflict, bind it to stem/revisions/draft hash, require separate confirmation, consume before save, and recheck disk revision. |
| T-04-24 | Information Disclosure | conflict payload | medium | mitigate | Return document content only for an allowlisted plan already open in the local day surface; never include absolute path or unrelated files; escape all display/copy data. |
| T-04-25 | Repudiation | hidden draft loss | medium | mitigate | Keep draft in state on invalid/conflict, warn only while dirty, expose copy/download, and return old/new revisions in status. |
| T-04-27 | Information Integrity | day palette migration | medium | mitigate | Consume validated `theme_css`, keep `DAY_CSS` layout-only, and use fixed semantic status variables plus text rather than custom accent. |
| T-04-SC | Tampering | package supply chain | low | accept | No editor/diff framework or external package is introduced. |
</threat_model>
