<interfaces>
Use the interfaces created by 04-03 directly:

- `theme.derive_theme(source)` and `theme.theme_preview(source)` are the only color-computation paths.
- `theme.theme_css(config)` is the only CSS-variable producer.
- `theme.pick_native_accent(initial)` is the direct CLI-process seam; `launcher.run_native_picker(source)` is the tested source/`.pyz` child bridge and returns `{available, source, reason}` without persistence.
- `theme.cmd_theme(args)` is the CLI twin for route operations.

`POST /api/theme` accepts only these JSON shapes: `{action:"preview", source}`, `{action:"pick"}`, `{action:"save", source}`, and `{action:"reset", confirm:"RESET"}`. It derives every response token server-side and accepts no CSS, path, rendered pair, or override field.

Renderer signatures may gain an optional `theme_css`/`config` argument, but their current default behavior and static CLI outputs must remain compatible.

Create these presentation contracts without a plugin framework:

- `presentation.render_surface(view, adapter=None) -> html`; the default adapter produces semantic HTML from a behavior-free view dictionary.
- `presentation.surface_shell(...)`, `teaching_step(...)`, `context_line(...)`, `state_panel(...)`, and `details_section(...)` are escaped native-element primitives shared by index/report/settings and available to quiz/study/day/lesson renderers. `teaching_step` accepts a concise label/prompt, body, immediate status slot, and one primary action, with optional secondary details.
- Optional enhancement hosts retain their semantic fallback children and expose stable `data-presentation-*` hooks. An alternate adapter receives the same view data but cannot own scoring, persistence, routing, scheduling, or evidence decisions.
</interfaces>
</context>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> `/api/theme` | Page-supplied color/action attempts to preview or mutate host settings. |
| LAN client -> local installation | The unauthenticated daemon may be reachable from other devices when `--lan` is enabled. |
| Settings -> every rendered page | One malformed setting could otherwise break all visual surfaces. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-13 | Tampering | `/api/theme` save/reset | high | mitigate | Require loopback, same-origin JSON action; validate source only; derive tokens server-side; write through settings validator/atomic writer. |
| T-04-14 | Denial of Service | `/api/theme` native picker | medium | mitigate | Restrict to loopback; spawn only the current source/`.pyz` with fixed no-shell argv; bound/validate child JSON; return unavailable on spawn/Tk/output failure and keep color input usable. |
| T-04-15 | Information Integrity | shared CSS rollout | high | mitigate | Generate all page tokens through one tested function and assert rendered equality across routes; semantic states never depend on source accent. |
| T-04-16 | Elevation of Privilege | theme request fields | medium | mitigate | Accept no filesystem path, CSS string, or derived-token object; operations use `handler.root` and allowlisted actions only. |
| T-04-SC | Tampering | package supply chain | low | accept | No package-manager install or remote asset is introduced. |
</threat_model>
