## Trust Boundaries

| Boundary | Description |
|---|---|
| instructor browser -> picker | The picker reads the local bank registry; it must never render bank content beyond objective ids/titles |
| picker -> deep_link_return_url | The response is an unsigned form POST; only reachable from a verified LtiDeepLinkingRequest launch |
| LMS iframe -> player | The player is the quiz surface; the frame-ancestors policy is the only framing gate |
| player -> runtime | The learner must never reach explain_payload before a recorded response (evidence-log gate) |
