## Trust Boundaries

| Boundary | Description |
|---|---|
| tool -> platform token endpoint | The client assertion is signed with the tool's private key; the token is scoped to the granted AGS scopes |
| tool -> LMS gradebook | The score payload is a one-way copy; the LMS is the instructor's record, never itembank's |
| runtime report -> passback | The score source is the one scorer's report; the LTI surface never recomputes |
| LTI surface -> evidence store | The LTI surface must add no writes beyond the existing session/attempt paths |
