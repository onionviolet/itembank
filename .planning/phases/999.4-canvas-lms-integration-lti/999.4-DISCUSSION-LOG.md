## The wrap seam (D-01)

| Option | Description | Selected |
|--------|-------------|----------|
| Call the daemon's `handle_api_*` functions in-process | One dispatch; "wrapping the JSON commands" literally; the MCP note's precedent | ✓ |
| Re-call the JSON API over HTTP to itself | Loopback self-call; works but adds a socket round-trip and a second framing | |
| Reimplement session/scoring in `surfaces/lti.py` | Violates §4.2 | |

**Choice:** in-process call of the daemon handlers (or the same
`session.do_start` seam they use). **Notes:** the LTI surface is a client of the
same handlers, exactly as the MCP tool table is a projection of `API_ROUTES`.
No new `/api/*` route, no `API_ROUTES`/`SURFACE_PARITY` change, and
`check_api_route_scope` stays green — a grep-style test enforces it.

## Passback boundary (D-04 / R-02)

| Option | Description | Selected |
|--------|-------------|----------|
| AGS score copy at session completion, `PendingManual` for pending prose | Outbound-only, opt-in per launch, never auto-grades | ✓ |
| Live partial scores per item | More Canvas-gradebook churn; contradicts "at completion" | |
| No numeric passback at all | Degrades to completion status only (R-02 fallback) | |

**Choice:** outbound score copy at completion; `short` items pending → the
graded fraction with `gradingProgress: PendingManual`. **Notes:** answers the
"no hosted gradebook" constraint: itembank stores no gradebook, the LMS holds
the instructor's record, evidence stays local. Reversible to completion-only if
the user rejects numeric writes (R-02).
