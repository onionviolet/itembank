<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| evidence log → retention projection | Locally writable append-only bytes become learner-facing claims. |
| CLI filters/settings → derivation | Untrusted strings and numeric configuration affect filters, windows, thresholds, and weights. |
| report payload → public surface | Derived data may be exposed while answer keys, private tiers, paths, and provider payloads must remain private. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Tampering | evidence capture / retractions | high | mitigate | Capture once, apply the existing compensating-retraction and accepted-mark semantics, hash ordered live identities into provenance, and test append-after-capture immutability. |
| T-10-02 | Tampering | retention settings | high | mitigate | Bound every numeric field in the published schema and reject contradictory threshold/range pairs with named errors. |
| T-10-03 | Information Disclosure | report contract | high | mitigate | Publish an explicit allowlisted derived shape; tests reject answer keys, hidden tiers, filesystem paths, provider payloads, and model interaction content. |
| T-10-04 | Denial of Service | large evidence log | medium | mitigate | One materialization and one deterministic grouping pass per snapshot; no per-objective log rescan and no network dependency. |
| T-10-05 | Repudiation | recommendation provenance | medium | mitigate | Every claim carries cutoff, zone, window, filters, live count, settings version, and snapshot id; renderers cannot silently drop them. |
| T-10-SC | Tampering | package supply chain | low | accept | This plan adds no npm, pip, or cargo dependency and remains stdlib-only. |
</threat_model>
