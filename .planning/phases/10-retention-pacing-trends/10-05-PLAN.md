## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser identifiers/actions → daemon | Subject/objective/window/snapshot/override inputs are untrusted. |
| derived payload → public DOM/API | Safe summaries must be separated from private bank/session/model fields. |
| optional local/network services → UI | Anki/model/network failure must not become false current evidence. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-10-19 | Tampering | focused start/report filters | high | mitigate | Identifier allowlists, bounded windows, server recapture, snapshot equality, and existing forbidden-field guard. |
| T-10-20 | Information Disclosure | Today/report DOM/API | high | mitigate | Render allowlisted derived fields only; automated negative scans cover paths, answers, rubrics, keys, hidden tiers, and provider/model payloads. |

| T-10-23 | Repudiation | UI recommendation/action | medium | mitigate | Visible snapshot claim plus matching session/selection/completion/override evidence identities. |
