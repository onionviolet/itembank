<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| shell process -> sidecar process | The shell's lifetime must bound the sidecar's; a hard kill must not orphan it |
| local webview -> loopback daemon | The window renders daemon content; the token gate is the only new secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-13-05 | Denial of Service | orphaned sidecar on hard kill | high | mitigate | Job Object with KILL_ON_JOB_CLOSE assigned immediately after CreateProcess (D-05); the taskkill fixture proves it |
| T-13-06 | Spoofing | second instance | medium | mitigate | Named mutex + attach-or-refuse; no competing sidecar ever starts |
| T-13-07 | Tampering | sidecar binary | high | mitigate | The sidecar ships inside the signed bundle; updater signatures (13-04) verify the installer |
| T-13-08 | Information Disclosure | token handling | medium | mitigate | The token lives in the shell's memory and the daemon's memory only; never logged, never persisted |
| T-13-SC | Tampering | crate supply chain | high | mitigate | Cargo.lock committed, crate licenses reviewed, versions pinned (D-14) |
</threat_model>
