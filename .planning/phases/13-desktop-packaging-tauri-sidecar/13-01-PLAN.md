## Trust Boundaries

| Boundary | Description |
|---|---|
| sidecar stdout -> shell | The handshake is the only new protocol surface; it must be parseable and unforgeable in practice (the token is the secret) |
| loopback port -> any local process | Any local process can reach a loopback port; the token gate is the authentication |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-13-01 | Spoofing | loopback port access | high | mitigate | Per-launch token generated at sidecar start, required on shell-used routes, never persisted (D-04) |
| T-13-02 | Tampering | handshake framing | medium | mitigate | Fixed, shared framing constants parsed by both the shell and the tests; a malformed line fails the parse, never a silent fallback |
| T-13-03 | Denial of Service | second-launch race | medium | mitigate | Attach-or-refuse-by-name per D-06; no competing sidecar starts in any fixture |
| T-13-04 | Information Disclosure | token in process list | low | mitigate | The token travels on the sidecar's stdout only (inherited by the shell), never as a CLI argument visible to other processes |
| T-13-SC | Tampering | package operations | high | mitigate | This plan performs no package operation; the shell/installer toolchains are plan 13-02/13-03's pinned additions |
