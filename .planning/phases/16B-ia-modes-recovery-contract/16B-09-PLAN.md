<objective>
Make the first launch of a fresh install useful with nothing granted, nothing
configured, and nothing reachable.

`REQUIREMENTS.md` APP-03 requires that "First launch offers a clearly synthetic,
removable sample course and a skippable, replayable walkthrough reachable
without granting source roots or configuring an agent". Its fixture is "the 16B
first-launch interruption scenario running the clearly synthetic sample course
and walkthrough with no roots granted, no agent configured, and the network
disabled, asserting offline help routes from named error codes".

`16B-RESEARCH.md`'s Don't Hand-Roll table names the failure mode directly: a
course generated on first run by calling an agent would require exactly the
agent configuration the requirement says must not be needed. So the sample
course is fixed bytes.

Decisions already made, cited, and never re-derived here:

- **`16B-DECISIONS.md` `## D-16B-5`**: first-run and shelf state live in
  `_ia/walkthrough.json` and `_ia/sample_course.json` under the daemon root,
  each written through one helper that writes a `.tmp` and calls `os.replace`,
  the identical atomic-rename shape `runtime.write_session` uses. Neither is a
  settings key and neither is evidence.
- **`16B-DECISIONS.md` `## D-16B-6`**: the sample course ships as literal Python
  strings in a new root module `sample_course.py`, is materialized into
  `<root>/_sample_course/`, and that directory is added to `.gitignore` and to
  `cmd_guard`'s skipped-directory list, because guard exists to stop a real bank
  being committed and nothing gitignored can be committed.
- **`16B-DECISIONS.md` `## D-16B-7`**: exactly one new mutating route,
  `POST /api/shelf`, with `SHELF_ALLOWED_FIELDS = ("action",)` and four actions;
  `check_api_route_scope`'s literal `12` becomes `13`; `SURFACE_PARITY` gains
  one row.
- **`16B-UI-SPEC.md` "First-Launch, Sample Course and Walkthrough Contract"**,
  the whole seven-row table, exact copy, binding verbatim, including the
  reachability constraint and the mandatory `(Sample)` suffix rule.
- **`16B-UI-SPEC.md` Copywriting Contract**, the destructive-confirmation row
  and the walkthrough-offer row.

Purpose: make the first five minutes of a fresh install work with nothing
configured, and make the synthetic thing on the screen obviously synthetic.
Output: one bundled course, two atomic state records, one mutating route, and
the APP-03 fixture executed.
</objective>
