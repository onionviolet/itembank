<objective>
Turn a broken lesson reference into an actionable, by-item-number failure, and publish the whole
`lesson.*` namespace through every place that has to know about it in one commit.

**User story (MVP framing, from ROADMAP Phase 3 Goal):** **As an** author tagging items against a
lesson, **I want to** be told by item number which reference points at a heading that does not exist,
**so that** I fix it before a learner clicks a link into nothing.

Purpose: ROADMAP Success Criterion 3 is the acceptance gate for this phase and it says *fails*, by
item number, never a render-time crash. This plan is that gate. It also carries the phase's single
highest-risk mechanical detail: a new dotted code namespace touches two files that are neither
`model.py` nor a `surfaces/` file, and both are exercised by CI against live lint output, so a code
added without them fails the build the first time a fixture triggers it rather than the moment it is
written.

Output: four published codes, one optional `lint` parameter, two fixtures that exercise all four
through CI, and REQUIREMENTS.md reconciled with the ROADMAP.
</objective>
