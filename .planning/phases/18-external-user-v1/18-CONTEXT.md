## Domain

A friend with no knowledge of this project installs itembank, is walked
through setup by an AI agent reading the public repo, and gets real value
from the shipped loop. One learner per installation; no accounts, auth, or
multi-tenancy; stranger-safe privacy defaults. The phase closes after 17B
with a real cold install by a second person.

## Decisions

- **D-01 Packaging conflict resolved (IL-20260815-11).** The delivery
  vehicle is the Phase 13 desktop shell (the shipped Tauri-sidecar
  packaging work in `phases/13-desktop-packaging-tauri-sidecar/`) wrapping
  the browser-served UI that 17A-CONTEXT D-08 fixed as the single canonical
  shell. Nothing chooses between shells: the packaged app and the browser
  reach the same served pages from the one runtime (IL-20260816-02). The
  historical "no build step" reading and the miscited DEL-02 ground against
  PyInstaller (constraint audit F9, F15) are both dead: a build step is
  permitted on merit per the 2026-08-09 amendment, and no PyInstaller-class
  freezer is adopted because the Phase 13 shell already exists and shipped.
  Any new packaging tool this phase touches goes through
  `SUPPLY-CHAIN-POLICY.md` section 3.
- **D-02 Code signing (V2-DEL-01, trigger fired 2026-08-14).** This is a
  purchase decision and stays a checkpoint:decision for Weibao, presented
  with real costs in the plan: Windows Authenticode OV certificate
  (roughly 100 to 400 USD per year, exact quote gathered at execution),
  Apple Developer Program (99 USD per year) if a macOS artifact ships, or
  ship unsigned with the SmartScreen and Gatekeeper workarounds documented
  exactly where the user hits them. Recommended default: unsigned for v1
  with documented workarounds, revisit on wider distribution. Whatever the
  answer, the A10 criterion is satisfied by recording a dated cost
  decision, not by signing itself.
- **D-03 Capability disclosure manifest.** A machine-readable JSON document
  named `capabilities.json`, generated by the repository's own tooling and
  shipped both in the repo and as a release asset beside the packaged
  artifact. Contents: schema_version, itembank version, format contract
  version, the command surface (each command with a since-version), served
  routes, skill library index, and a changed-for-agents changelog section
  per release. It is static and local: reading it is not a network event,
  no telemetry, and the existing disclosure-gated updater is the only
  network path that ever fetches a newer one. Consumers: any coding agent
  onboarding cold (README points to it), and the promoted Phase 999.3 MCP
  surface (server/discover payload) as a named future consumer. This is
  additive surface on shipped ground (`itembank update`, `usage`,
  `schema`); no new authority, no runtime behavior change.
- **D-04 Cold-agent onboarding transcript (A10 check 2's fixture).** One
  agent, one run, recorded: a fresh agent session is given only the public
  repo URL and the README onboarding section, and walks a simulated new
  user through verify-Python, fetch, launch, author a first bank from the
  user's own material, and a first graded sitting. The transcript lands at
  `.planning/phases/18-external-user-v1/18-COLD-AGENT-TRANSCRIPT.md`,
  redacted of any real paths or personal content. A failed walkthrough is
  a defect list against README or error copy, fixed and rerun.
- **D-05 A10 verification mechanics.** Each of the six criteria gets a row
  in `18-GATES.md` with its concrete check and evidence pointer. Criterion
  1 and 6 are exercised on the packaged artifact; criterion 5 is verified
  on a fresh install (no repo `itembank.json`): update_policy resolves to
  opt_in and nothing phones home without disclosure (the D-13 divergence
  stays repo-only). The closing check is the real second-person cold
  install; it may be Weibao's friend and is a human checkpoint.
- **D-06 Scope honesty copy.** User-facing docs sell only the shipped
  bank, lesson, session loop and whatever 14A-17B actually shipped by
  execution time; the course workspace is described as being built where
  it has not. The plan carries the exact README wording.
- **D-07 MCP not built here.** The manifest is designed with the MCP
  surface as a consumer, but 999.3 remains its own promoted phase and no
  MCP code lands in 18.
