## How enumeration works (no second list, no source regexes)

`tools/capabilities_manifest.py` imports the live modules. For commands it
calls `surfaces.cli.main()` with `argparse.ArgumentParser.parse_args`
temporarily replaced by a capturing raiser, so the fully built parser is
walked (its `_SubParsersAction._choices_actions`) while no command ever
runs. Routes come straight from `daemon.ROUTES`; skills from a directory
listing of the mirrored roots.

## SINCE seeding

Every command registered today predates the manifest, so all 52 SINCE rows
are seeded "0.3.0" (the current release); no command had a discoverable
older since-version and none needed one. A registered command absent from
SINCE makes the generator raise SystemExit naming the command, so a future
command cannot ship undisclosed; the roundtrip test then fails on the stale
checked-in manifest as well.
