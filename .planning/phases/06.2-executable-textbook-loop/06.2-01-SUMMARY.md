# Phase 06.2 Plan 01: Gate Grammar, gate_skip Event, Response Context, gate_state — Summary

**The evidence layer is locked before any learner-facing pixel ships: the
`[GATE:]` grammar, the `gate_skip` event, the response `context` field, and
the read-side `gate_state` derivation.**

## Performance

- **Duration:** ~55 min (codebase survey + Tasks 1-3 + closeout)
- **Completed:** 2026-08-10
- **Tasks:** 3
- **Files modified:** 9 (1 created, 8 modified)

## Accomplishments

- `model.py` parses `[GATE: required|recommended|off]` from the lesson
  preamble with the exact `[LESSON-SRC:]` grab pattern; absent → `recommended`;
  an invalid value is a named `lesson.invalid_gate` lint error, never a
  render-time crash (T-062-01). A no-gate bank parses additively — the lesson
  dict gains exactly the one new `gate` key, and the Phase 3 golden parse
  fixture was extended with `"gate": "recommended"`.
- `model.py` adds `lesson.check_ref_unknown`: every `[!CHECK: <id>]` must
  resolve to an item in its own bank (D-01). The message is the single
  `CHECK_UNRESOLVED_COPY` constant (UI-SPEC §15 verbatim), defined once in
  model.py; the plan's "imported from 3.1" intent is honored by construction
  because 3.1 shipped no such constant (its plans 3.1-05..07 never executed —
  verified by grep), so 6.2 mints the one definition the renderer will import.
- `evidence.py` appends `"gate_skip"` to `KNOWN_EVENT_TYPES`; `gate_skip_event()`
  mirrors `day_tick_event()`/`mark_event()` (own envelope, narrow
  `(session_id, check_item_id)` dedupe key, `ValueError` on `off`/unknown
  modes) and structurally carries **no `score` key** — criterion 8's concrete
  form (T-062-02).
- `response_event()` gains the additive `context="quiz"` parameter; the one
  new call site (the plan-06.2-03 check route) will pass `"lesson_gate"`.
  `schemas/response.schema.json` requires `context` (enum `quiz|lesson_gate`)
  in the response branch, adds the descriptive `gate_skip_event` $def to
  `oneOf` (and removes it from the catch-all enum), and `schemas/lint_error
  .schema.json` publishes the two new codes. The disposable index projection
  gained a `context` column (`INDEX_VERSION` 2→3), and `objective_history()`
  rows carry `context` through both the indexed and fallback paths.
- `gate_state(log, session_id, check_item_id)` is a pure read over
  `live_events()`: pair-level resolution (any live lesson-gate clear wins over
  a prior skip; a live skip with no response is skipped), session-scoped by
  construction, retraction-aware (a retracted clear or skip restores the prior
  state), and it performs no writes and keeps no cache (D-06).
- `tests/gate_roundtrip.py` ships the GATE-01..04 evidence-layer fixtures in
  the repo's stdlib `fail()` harness.
