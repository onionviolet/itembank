## Gate strength

| Option | Description | Selected |
|--------|-------------|----------|
| `[GATE: required\|recommended\|off]`, default `recommended` | Ship all three, default to the honest one | ✓ |
| Hard gate only | The next passage cannot render until cleared | |
| No gate | Reading is always linear and free | |

**Choice:** build all three (Directive §3). **Notes:** the deciding argument is not the mastery-learning literature — it is that a hard gate is theater on a plaintext file the learner owns. It is a claim the product cannot keep. The loop's value is the *return*, not the wall, and a recorded skip preserves that value better than a wall does because skipped-and-still-unclear is a prioritizable signal while a wall learns nothing.
