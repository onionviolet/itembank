# Phase 06.2 Plan 02: The Gate Band, Three Renderings, Truncation, Mode-Degrade — Summary

**The reserved slot is live: one render path, three policies, zero
JavaScript, same box.**

## Performance

- **Duration:** ~50 min (Tasks 1-3 + closeout)
- **Completed:** 2026-08-10
- **Tasks:** 3
- **Files modified:** 2 (surfaces/lesson.py, tests/gate_roundtrip.py)

## Accomplishments

- `surfaces/lesson.py` activates 3.1's D2 slot into the live gate band: a
  `<section class="gate">` with the same box metrics (space-3 padding, 1px
  `--line`, `--r-3`, space-4 margin, 66ch measure), the Ledger header
  (`Check · required to continue` / `Check · recommended`), the check item's
  public projection at text-body 16/1.5 (stem and options only — no key,
  rationale, distractor analysis, or objective line), and one
  `<form method="post">` whose two named submit buttons are `check` first
  and `skip` second, both at 44px via the shared `.go` control. No `<script>`
  element ships in a gated page without a glossary.
- G1 truncation under `required`: the server emits nothing below the first
  uncleared check — `_render_blocks` sets a stop flag at the band,
  `render_markdown`/`lesson_page` stop, and the boundary renders
  `{n} more sections below this check.` / `1 more section below this
  check.` (two copy rows only). The no-leak fixture proves absence across
  HTML and text content for headings, paragraphs, lists, tables, code
  blocks, `[!KEY]`/`[!EXAMPLE]`/further `[!CHECK:]` ids, backlinks, TOC
  entries and glossary entries.
- G2 under `recommended` renders the whole lesson with the band in flow;
  `off` (or no session, or the static build) renders 3.1's reader unchanged.
- Mode-degrade: a declared `required` gate in diagnostic/exam sittings
  renders complete (no truncation, no skip control) with the exact line
  `This sitting holds feedback until it ends, so checks do not gate reading
  here.` and records no `gate_skip`.
- TOC filtering (`More sections appear as you clear each check.`) and the
  glossary-appendix filter (terms marked in revealed sections only) apply
  exactly when truncation happened.
- An unresolvable `[!CHECK:]` renders the D1 labelled rule with the
  warn-tone `CHECK_UNRESOLVED_COPY` line and never gates — reading
  continues (authoring errors never block readers).
- The `.gate` CSS block plus the boundary rule is the phase's exactly-one
  addition to the lesson CSS layer, with no new family, size, weight, or
  colour literal.
