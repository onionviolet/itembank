## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS file manager → shell → interpreter | Each shim is executed by the OS with the learner's own privileges and chooses what runs next |
| downloaded release → local filesystem | A shim and an artifact arrive together from the network and are trusted by the double-click |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02.1-05 | Elevation of Privilege | `launchers/itembank.command` | medium | mitigate | The shim changes into its own directory resolved from `$0` and invokes `python3 itembank.pyz` by an explicit name beside it, never a path taken from the caller's environment or a wildcard match |
| T-02.1-06 | Tampering | `launchers/itembank.desktop` `Exec=` | medium | mitigate | The `Exec` line resolves the entry's own directory from the `%k` field code and runs a fixed command; no field code that interpolates a user-supplied filename into the command is used |
| T-02.1-07 | Tampering | downloaded release directory | high | mitigate | `SHA256SUMS.txt` covers every shim as well as the artifact, and README documents the one-line verification command, so a substituted shim is detectable before the first double-click |
| T-02.1-08 | Spoofing | macOS Gatekeeper quarantine | low | accept | Fully closing this needs a paid Apple Developer signing certificate, deferred by `V2-DEL-01`. Accepted for this milestone with the workaround documented rather than left to surface as an unexplained failure |
| T-02.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs no package from any registry and vendors no third-party artifact. The mitigation is the project vendoring policy, not the absence of dependencies: any third-party artifact is vendored at a pinned version with a recorded SHA-256 and a named license review before use, per the KaTeX precedent (`09-03-PLAN.md`). Nothing in this plan reaches that gate. (Restated 2026-08-10 — constraint audit F5.) |
