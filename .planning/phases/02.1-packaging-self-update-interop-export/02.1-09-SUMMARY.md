## Decisions Made

- **The clock lives in its own record, not a placeholder manifest.** The manifest schema requires a real `path` and a 64+ char `sha256`; a manifest written after a check that installed nothing would carry an invented digest for an artifact that does not exist, and `handoff()` reads that document to decide which file to spawn. `updates/check_state.json` keeps the one document with execution consequences honest.
- **`reached` is the reachability contract.** GitHub charges its budget for any request that arrives, even one answered with an error status; a request that never left the machine charges nothing. `background_check` stamps exactly when `reached` is true, so the interval is spent only when it was earned.
- **`notified_at` and `checked_at` are written separately on purpose.** The disclosure launch records consent but not a clock tick, so the next launch checks immediately; `write_check_state`'s merge makes the two writes composable.
- **The disclosure sits after `may_check`.** A fresh folder with no settings file reads the schema default `opt_in` and returns at the policy gate -- no print, no request, exactly as before.
- **D-13 is documented, not reversed.** The verification report's own second option (raising the schema default to `check_on_launch`) would make every fresh install phone home by default; the taken option keeps both halves of D-13 and removes only the "silently" from the disagreement.
