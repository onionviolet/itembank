**Both denominators, stated.** The auto figure is 9 correct of 18 auto
attempts, which is attempts and not items. Per item it reads differently: all
nine auto-scorable items ended correct, four of them on the first try and five
after two, three, or four tries, and the practice-mode hold is what produced
the extra attempts. Neither number is the accuracy of a first sitting on its
own, and a consumer must say which one it is using. The
human figure is a separate denominator and is not summed with it: 1 mark of 1
markable item, verdict fail. At close `pending_manual` is 0 because that mark
settled, not because nothing needed marking.

## Named consumers

Each plan below must cite this file rather than minting a synthetic fixture for
what it covers. The corpus does not replace those plans' generated corpora
wholesale, because no real item text may enter this repository; it replaces the
claim that a synthetic corpus is sufficient evidence.

- **Phase 14B, three-domain graph tracer.** This course's objective map, its
  prerequisite shape, and its recorded treatment decisions (two direct-reading,
  two lesson-plus-practice, in `course.md`) are one of the tracer's domains, by
  pointer. `14B-06`'s freeze gate already checks that Phase 13.9 has been
  walked; this file is what that check reads.
- **Phase 15A, four-subject recommendation review.** This course's treatment
  decisions and their recorded outcomes are one of the four subjects reviewed.
  The per-objective table above is the outcome half; `course.md`'s objective
  table is the decision half, including its stated reasons for choosing direct
  reading over a generated lesson.
- **The Phase 3.2-style warning-calibration obligation.** This bank counts in
  the corpus that calibrates authoring warnings. It is a real bank, authored
  against a real source, that a real learner sat, which is exactly the sample a
  false-positive rate cannot be measured without.

## How to reproduce

From the course root, with no arguments invented:

```bash
python3 itembank.py report _attempts/session_4022b08512e0.json
```

```bash
python3 itembank.py evidence --objective emt:direction.when
```

```bash
python3 itembank.py stats ems-authority-and-direction_bank.md
```

The first reproduces every count in "The sitting" and "Per item-level
objective". The second reproduces one objective's live history and returns an
honest zero for an objective with no items rather than an error. The third adds
empirical distractor usage over this same evidence, which is the check that
improves with every further sitting.

Run `python3 itembank.py guard .` in the repository root after any edit to this
file.
