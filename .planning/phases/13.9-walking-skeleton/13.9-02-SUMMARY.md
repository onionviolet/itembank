## The plan defect, found by executing it

Task 1 instructs the author to put a `## TERMS` block in the lesson file.
**A TERMS block in that file is never read.** `[LESSON-SRC:]` replaces only a
bank's `## LESSON` section, so the glossary has to live in the bank's own
preamble. Lint caught it as five `[[term]] has no entry in ## TERMS` errors,
which is the linter working exactly as intended.

Resolved by moving TERMS into the bank and removing the inert copy from the
lesson file rather than leaving two glossaries with one reader. The lesson file
now says where its glossary lives and why. **Anyone amending 13.9-02-PLAN.md
should fix Task 1's instruction.**
