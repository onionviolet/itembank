<objective>
Bring the last two writers into the fold. `itembank serve` writes an attempt markdown file directly
today, and `itembank day` writes `daily_log.md` directly; after this plan both write events through
the one writer and both files are renders.

Purpose: EVID-03 says one evidence store replaces `_attempts/*.md`, session JSON and `daily_log.md`,
and each of those becomes a view over it. Plan 01-09 did the first two. This plan does the third and
converts the graded browser sitting, which is the surface a real sitting actually happens on.
`.planning/codebase/CONCERNS.md` records both of the writers this plan retires: the attempt file
rewritten in full on every answer (`surfaces/quiz.py:172`) and the fragile header-mapped
`daily_log.md` reader (`surfaces/day.py:434-457`), which is untested for concurrent writes.

It also closes the last EVID-07 gap on the browser path: the page already knows how long the learner
looked at an item, so it reports the elapsed milliseconds on its POST, and `serve` gains `--mode` so
EVID-08 is true on both surfaces rather than only on the CLI.

Output: `day_tick_event`, `render_daily_log`, a `serve` that appends events, a page that reports its
own timing, a `day` that ticks by appending, and the tests that pin all of it.
</objective>
