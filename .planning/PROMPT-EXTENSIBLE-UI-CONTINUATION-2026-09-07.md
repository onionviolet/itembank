1. Semantic roles define meaning and state.
2. Shared primitives implement accessible behavior once.
3. Presentation profiles arrange navigation, density, emphasis, and layout.
4. Appearance themes provide color, typography, spacing, geometry, and motion

and integrations may enter as capability adapters at named seams. Each adapter
