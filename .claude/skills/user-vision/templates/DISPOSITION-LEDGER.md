# Disposition ledger

**Purpose:** give every substantial idea one durable route so viable breadth is
preserved and no idea is silently deleted for minimalism.

**Rule:** each proposal gets exactly one disposition from the seven below.
Rejections are append-only and keep every field. See the skill's
`references/disposition-vocabulary.md` for the full definitions and required
fields before assigning a disposition.

## Active dispositions
