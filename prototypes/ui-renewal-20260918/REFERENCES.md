# UI showcase reference index

Updated September 18, 2026. Design patterns, not imported code or verified product parity.

## [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)

- Pattern: An ordered course outline and a focused teaching stage.
- Showcase: Course context and a large activity canvas. No simulated teacher or classmates.
- Evidence: Official repository reviewed September 18. Earlier hands-on trial is separate evidence.

## [LiaScript](https://liascript.github.io/)

- Pattern: Learner-controlled explanation stages over readable source material.
- Showcase: Explicit progression, optional explanation and a static lesson equivalent.
- Evidence: Live first-stage advance inspected September 18. Full course parity was not tested.

## [H5P](https://h5p.org/question-set)

- Pattern: A sequence can contain different response forms and a clear review destination.
- Showcase: Question-format gallery and explicit feedback/next states. No external scorer.
- Evidence: Official Question Set documentation and Interactive Book schema reviewed September 18.

## [Desmos](https://help.desmos.com/hc/en-us/articles/202529069-Sliders-and-Movable-Points-in-a-Graph)

- Pattern: Bounded controls linked to visible quantities and representations.
- Showcase: Time slider, linked bars, values, reset and a plain explanation.
- Evidence: Official slider/table documentation reviewed September 18. No calculator embedded.

## [Brilliant](https://brilliant.org/)

- Pattern: A problem and its visual representation share one learning space.
- Showcase: Diagram and response remain together. No tutor persona or mastery inference.
- Evidence: Current public homepage reviewed September 18. No signed-in course trial.

## [Python Tutor](https://pythontutor.com/)

- Pattern: Make program state and execution flow visible beside source code.
- Showcase: Prediction plus a learner-filled trace. We do not execute code or reveal computed states.
- Evidence: Official site checked September 18. This is a design adaptation, not its visualizer.

## [Runestone Academy](https://runestone.academy/ns/books/published/authorguide/directives/parsons.html)

- Pattern: Parsons problems ask learners to assemble mixed-up code blocks.
- Showcase: Reorder preserved code with keyboard/touch buttons. No scoring or automatic simplification.
- Evidence: Official author guide checked September 18. No Runestone library imported.

## [CodeMirror](https://codemirror.net/examples/basic/)

- Pattern: An editor separates the document, editing features and language support.
- Showcase: A plain editable draft demonstrates space and flow. CodeMirror is a future editor candidate.
- Evidence: Official basic-editor example checked September 18. This prototype uses a textarea, not CodeMirror.
