## Refined execution brief

Reimagine Itembank's overall interface and learning experience as one coherent
app. Revisit earlier alternatives including OpenMAIC, LiaScript, and H5P and
research additional strong examples. Adapt their best visual presentation,
interactive explanations, question flows, feedback, and navigation without
importing simulated speakers or classroom conversations.

Design from learner tasks and desired quality so the old interface does not
constrain the new one. Preserve assessment and data authority. Give desktop
and mobile intentional layouts, clear next actions, smooth transitions,
readable content, and accessible controls.

Run independent Astra investigations in parallel, reconcile them into one
design, and build a runnable showcase of the learning journey. Identify how
it fits into the real app, what can be reused, and what needs replacement.
Verify rendered results and distinguish showcase from production integration.

## Operation and ownership

Read scope: repository contracts, current code, previous local research and
public primary sources. No real learner banks or private source documents.
Write scope: this isolated prototype directory and additive vision capture.
The root agent owns showcase and synthesis. Three independent Astra reviewers
own research/references.md, research/flows.md and research/integration.md.
No commits, pushes, installed-app replacement or canonical learner-data writes.
External research sends public search terms only. No third-party source code
is copied. The showcase uses synthetic content and records no evidence.

## Acceptance

One coherent desk, course, lesson, practice, feedback, review and resume flow.
Desktop and narrow viewport inspection. Keyboard navigation, explicit advance,
reduced motion, and overflow checks. Practice is a labeled presentation fixture,
not a second scorer. No claim of human accessibility or learning acceptance.
Production adoption requires the exact runtime and packaging gates named in
the integration report. Removing this directory undoes the prototype.
