MATH 1400 / OBJECTIVE 02 / SOURCE §2.2

One-sided limits describe approach, not arrival.

A function can have a limit at a value even if it is not defined there. Compare the behavior from both sides before saying the approaches agree.

Source note. Stewart §2.2, pp. 76–83. This teaching text synthesizes the cited example.
