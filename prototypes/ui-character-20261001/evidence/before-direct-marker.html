Exactly equal is its own case.

Strictly greater means crossing the boundary. Greater than or equal means the boundary itself counts too.

Changing > to ≥ changes equality. The values on either side keep the same result.

Before writing the comparison, try one value below, one equal, and one above.

BOUNDARY LAB / REPAIR

Find the case that changes.

This function should count integers strictly greater than the limit. Inspect the equality case in this fixed example.

03

count_over.py · read-only teaching example

def count_over(values, limit):
    matches = 0
    for value in values:
        if value >= limit:
            matches += 1
    return matches
