# Synthetic question-family prototypes

Run `python3 prototypes/audit-question-families/families.py` from the repository
root. The printed loopback URL opens the staged case. `/blanks` and `/evidence`
open the other native form journeys. Each launch creates temporary synthetic
bank, sitting, journal and evidence files; stopping the server removes them.
No account, donor dependency, learner file, installed app or shared runtime file
is changed. These are prototypes, not accepted product question types.

Run `python3 tests/a2_question_families_roundtrip.py` for the executable gates.
Run `python3 prototypes/audit-question-families/polynomial.py '2*(x+1)'` for
advisory polynomial analysis. `acceptance.json` owns its authored input cases.

## Working slices and authorities

| Slice | Implemented behavior | Limit |
| --- | --- | --- |
| Answer then reason | Existing `PAIR` selection includes both independent MC children in bank order. Formal runtime submission commits either valid answer and advances. A fresh client derives the stage from the runtime cursor. | Exam/diagnostic only. Practice commitment and grouped evidence need new reviewed runtime contracts. No second stage cursor. |
| Multiple inline blanks | `{{color}}` and `{{count}}` map exactly once to stable existing fill field IDs. Native labelled controls send the ordinary fill response. Draft correction and journal CAS survive reopening. | Prototype presentation convention only. No new authored marker grammar is accepted. |
| Evidence selection | Three fixed source spans bind stable anchor IDs to offsets, exact quotes and a passage fingerprint. Existing multi options and runtime own the response/verdict. | Whole predefined spans only. No free selection, first-error grading, or general annotation format. |
| Polynomial analysis | Exact rational coefficient vectors, degree at most four, expanded-form inspection and two named synthetic misconception cases. Boolean equivalence delegates to the existing runtime numeric-fill scorer. | Advisory analysis only, no settled session/evidence writes. No CAS library, implicit multiplication, variable division or general symbolic math. |
| Branch/checkpoint | Two distinct static teaching branches derive from the committed choice. Branch content opens only after both responses close. Presentation position and completion use the existing journal and undo. | Static transcript and simulated 0 to 60 second position, not a video player or verified reading measure. No correctness-controlled assessment graph or new assessment cursor. |

The synthetic `fixtures/bank.md` is coherent Markdown. Forms use native radio, checkbox, text, number
and button controls without JavaScript. Visible labels and focus outlines are
present. Automated structural checks and a browser keyboard journey do not
certify human screen-reader, touch, reflow or learning-transfer acceptance.

## Recovery and retained gates

The sitting and ordinary evidence are canonical. The journaled presentation
sidecar stores the accepted bank fingerprint, original unfinished entry and
observation position only. A stale bank, stale passage, stale item or stale
sidecar revision refuses the action and preserves the existing data. Committed
drafts remain archived in the sidecar but disappear from active response views.
Writes to that sidecar use `journal.commit_operation`, and undo uses
`journal.undo`. The prototype HTTP server is serial; it makes no production
concurrency, daemon-restart or crash-reconciliation claim.

F4 domain adapters require a named objective, pinned checker and validated
isolation before execution. F5 media/reviewer workflows require a named
objective, consent/storage rules and review rubric. F7 executable Parsons needs
distractor/indentation semantics, a declared isolated runner and prediction
commitment before execution. F8 variants and graphical/workspace domains need
seed plus checker revision, model validity, meaningful property tests and
difficulty review. F10 practical simulations need a scientifically validated
objective/model and interaction trial. None of those triggers is established
by these synthetic slices. Their backlog dispositions remain intact.
