## Construct, source, and authority checks

The studio starts in placement mode with a visible bank. Typed mode offers a
bank toggle. Placement always supplies labels and moving a label clears its
previous location. Those are observed code paths, not an independent browser
test. Alphabetical bank ordering does not expose the location mapping.
The source contains all four labels, so showing their names as public options
is necessary response content rather than disclosure of the private mapping.

The candidate's four associations agree with `figures.md#source-figure-2`.
The rainfall candidate preserves Monday, Gauge A = 12 mm, Gauge B = 18 mm,
and both 24-hour intervals from `figures.md#source-table-1`. Its rubric asks
for direction, difference with units, and the relevance of equal intervals.
It permits equivalent explanations and assigns no invented points or pass
threshold. This is an exploratory review proposal, not an official rubric.

The source dialog and Markdown preserve the original synthetic material.
Current diagram presentation is an adaptation. Reproduction and future source
presentation remain user choices. These specimens supply no evidence about
rights to reproduce a future third-party source. No such source was imported.

The validation script invokes the shipped CLI for lint, stats, coverage,
build, start, next, submit, and report. It does not parse a bank or calculate
a learner score. Its expected mapping constructs test inputs and assertions.
The runtime supplies the actual verdict. Public row identifiers, labels, and
destination names are valid response data. Private row categories, scoring
mappings, rationale, model answers, and rubrics remain excluded by the checks.
The hotspot-specific forbidden word is a fixture assertion, not a general rule
that public choices may never contain a correct response label.

The `dnd`, `short`, and `visual` hotspot declarations use shipped grammar.
The candidate validator uses disposable temporary roots and removes them on
exit. Three varied prose submissions are checked for null scores and pending
manual review. The coordinator reports these runtime checks passing. This
review inspected the script and candidates but did not repeat that execution.

## Exam-oriented use and remaining evidence

Use the actual tested objective and response demand to select a treatment.
A word bank changes recall into supported recognition or matching, which may
be appropriate but is not proof of the right cognitive demand. A diagram's
presence in a textbook does not establish that its labels are tested.
For a real EMT course, establish core or necessary-support relevance from the
current assessment profile before promoting a task onto the default path.
Teaching explanations may support exam performance without imitating an exam
item. Keep them labeled as teaching and out of exam-fidelity statistics.
