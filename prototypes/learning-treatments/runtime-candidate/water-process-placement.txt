WHY BEST: Each label matches the movement or change named by its source location.

KEY DISCRIMINATOR: Distinguish rising water, cloud formation, falling water, and water crossing land.

SECOND-BEST: Swapping the cloud formation and falling-water labels confuses a change within the cloud with movement away from it.

DISTRACTOR ANALYSIS:
- Evaporation at Location 3 would be correct if that arrow instead showed water leaving the lake and rising.
- Condensation at Location 3 would be correct if that location instead marked cloud formation.
- Precipitation at Location 4 would be correct if that arrow instead showed water falling from cloud to land.
- Runoff at Location 1 would be correct if that arrow instead crossed land toward a stream.

TRAP: Assigning labels based on closeness to the cloud instead of the specific movement or change.
