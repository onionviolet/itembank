# Sample plan

Synthetic fixture for `itembank day`. No real plan content lives in this
repository; this exists so the dated-table parser has something to fail against.

The parser finds a plan by looking for a table whose first column is a date, so
the table below is preceded by a decoy table that must be ignored.

| Timezone | UTC |
| Owner | nobody |
