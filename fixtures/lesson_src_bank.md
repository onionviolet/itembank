Q1. A patient is found unconscious and breathing. What is the first priority?   (difficulty: application)
[LESSON-REF: Managing the Unconscious Patient]
[OBJECTIVE: emt:airway]

A) Protecting the airway
B) Starting oxygen at the highest setting
C) Checking a blood sugar
D) Calling for a second responder

CORRECT: A

WHY BEST: The airway is the first thing that can kill an unconscious
patient, and positioning protects it without equipment.

KEY DISCRIMINATOR: The answer must protect the airway before anything else,
because an obstruction can develop in seconds.

SECOND-BEST: B. Oxygen matters, but a patient with an obstructed airway
cannot use it; this would be correct if the airway were already secured.

DISTRACTOR ANALYSIS:
- A) Correct: airway protection is the first priority.
- B) Oxygen is delivered, never stored; this would be correct if the airway were already patent.
- C) A blood sugar is a useful assessment; this would be correct if the question asked what to check after the airway.
- D) A second responder helps; this would be correct if the question asked about scene size-up.

TRAP: Reaching for a treatment before the airway is protected.

CONFIDENCE: high

Q2. Which statement about oxygen delivery is accurate?   (difficulty: recall)
[LESSON-REF: Oxygen Delivery Basics]
[OBJECTIVE: emt:airway]

A) A nasal cannula delivers a higher concentration than a non-rebreather
B) The delivered concentration depends on the patient's breathing pattern
C) A loose-fitting mask delivers more than the dial suggests
D) Oxygen is stored in the lungs for later use

CORRECT: B

WHY BEST: The delivered concentration depends on how the patient is
breathing, not just on the device, which is why reassessment matters.

KEY DISCRIMINATOR: The statement must describe delivery, not equipment
labels.

SECOND-BEST: A. A non-rebreather delivers more than a cannula; this would be
correct if the question asked which device delivers more.

DISTRACTOR ANALYSIS:
- A) The non-rebreather delivers more; this would be correct if the question asked which device delivers more.
- B) Correct: breathing pattern changes the delivered concentration.
- C) A loose mask delivers less, not more; this would be correct if the question asked about reassessment.
- D) Oxygen is delivered, never stored; this would be correct if the question asked about reservoir bags.

TRAP: Judging the device by its looks instead of by what the patient is
doing with it.

CONFIDENCE: high
