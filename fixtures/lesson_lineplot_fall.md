## LESSON

### Intercept on a falling line

Objective MATH-LINE-2: identify a common vertical shift even when slope is negative.
Source SYN-LINE-2: original synthetic example in this file.
Misconception: a negative slope means changing the intercept reverses the line.

> [!EXAMPLE]
> [LINEPLOT: -1,1,-1]
> Prediction: The starting rule is y = -x + 1. At x = -2, 0, 2, which plotted points will move if only the intercept changes to -1? Choose a prediction before using the control.
> Static explanation: Starting points are (-2, 3), (0, 1), (2, -1). With y = -x - 1, the points are (-2, 1), (0, -1), (2, -3). Every point falls by 2 while slope stays -1. The direction of the line does not reverse.
> Transfer: Without using the control, find the points at x = -2, 0, 2 for y = 2x + 0. Then say how replacing 0 with 2 changes each point.
