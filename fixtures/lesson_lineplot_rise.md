## LESSON

### Intercept as vertical change

Objective MATH-LINE-1: distinguish the slope from the starting y value in a linear rule.
Source SYN-LINE-1: original synthetic example in this file.
Misconception: changing the intercept changes only the point where the line crosses the y axis.

> [!EXAMPLE]
> [LINEPLOT: 1,0,2]
> Prediction: The starting rule is y = x + 0. At x = -2, 0, 2, which plotted points will move if only the intercept changes to 2? Choose a prediction before using the control.
> Static explanation: Starting points are (-2, -2), (0, 0), (2, 2). With y = x + 2, the points are (-2, 0), (0, 2), (2, 4). Every point rises by 2 while the slope stays 1. The table and plot show the same three points.
> Transfer: Without using the control, find the points at x = -2, 0, 2 for y = -x + 1. Explain which quantity sets the starting value and which sets the direction.
