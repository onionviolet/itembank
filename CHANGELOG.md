# Changelog

## 0.5.0 - 2026-09-19

- Added durable lesson reading and recovery, plus clearer question presentation
  and response recovery during practice.
- Added owner-backed Today tasks, persistent course ordering, and private note
  backup controls.
- Added dark and OLED appearance modes and refreshed local workspace controls.
- Fixed portable packaging of the workspace module and expanded discovery,
  adapter, package, and UI checks.

## 0.4.0 - 2026-09-09

- Added the course-first learner workspace across desk, learning, practice,
  activity, source, and settings routes.
- Added source registration, course operations, generated MCP tools, and the
  machine-readable capability manifest.
- Added comparison interactions and progressive lesson reading with static and
  offline fallbacks.
- Added reversible import, migration, recovery, and package validation work.
- Added a self-contained macOS arm64 app and DMG with a stable local workspace.

## 0.3.0 - 2026-08-10

- Published the local-first assessment runtime, authoring contract, learning
  surfaces, evidence records, and portable zipapp release.
