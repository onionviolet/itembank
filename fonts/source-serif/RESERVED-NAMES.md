# Reserved Font Names — Source Serif 4 (plan 03.1-06 Task 1)

The vendored file is the **unmodified upstream release** at tag `4.005R`
(adobe-fonts/source-serif), so the OFL 1.1 Reserved Font Name below binds
everyone downstream but not us: we ship the original face unchanged.

- Reserved Font Name: **`Source`**
  (OFL 1.1 condition 3 — *"No Modified Version of the Font Software may use
  the Reserved Font Name(s) unless explicit written permission is granted"*;
  copyright preamble: *"Copyright 2014 - 2023 Adobe … with Reserved Font
  Name 'Source'."*)

**Consequence recorded in the manifest:** a subset build must be renamed or
the files shipped unmodified. This repo ships unmodified, so no rename is
needed and the family name `Source Serif 4` used by `@font-face` names the
face exactly as upstream publishes it.

Source: `fonts/source-serif/LICENSE.md` (verbatim OFL 1.1 from tag `4.005R`).
