# Reserved Font Names — iA Writer Quattro (plan 03.1-06 Task 1)

The vendored files are the **unmodified upstream files** pinned to commit
`f32c04c3058a75d7ce28919ce70fe8800817491b` of `iaolo/iA-Fonts`, so the two
OFL 1.1 Reserved Font Names below bind everyone downstream but not us: we
ship the original face unchanged.

- Reserved Font Name: **`iA Writer`**
  (*"Copyright © 2018 Information Architects Inc. with Reserved Font Name
  'iA Writer'"*)
- Reserved Font Name: **`Plex`**
  (*"Based on IBM Plex Typeface — Copyright © 2017 IBM Corp. with Reserved
  Font Name 'Plex'"*)

**Consequence recorded in the manifest:** a subset build must be renamed or
the files shipped unmodified. This repo ships unmodified, so no rename is
needed and the family name `iA Writer Quattro` used by `@font-face` names the
face exactly as upstream publishes it.

Source: `fonts/ia-writer-quattro/LICENSE.md` (verbatim OFL 1.1 from the
pinned commit).
